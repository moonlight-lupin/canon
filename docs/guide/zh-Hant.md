# Canon 使用指南

Canon 幫助教會辦公室策劃主日聚會、打印次序單、投影，並管理各種名冊。本指南按每週的工作次序編寫。**粗體**字就是屏幕上顯示的按鈕或欄位名稱。

> **提示：** 每個標題、詩歌、禱文都可以用教會的各種語言輸入。簡體與繁體中文在各處都會自動轉換——畫面、印刷品、電郵，以及新朋友表格等公開頁面——中文只需輸入一次。對話框或某部分有好幾個這類欄位時，右上角的語言切換（**EN** / **簡** ……）可一次把所有欄位切換到同一種語言，按 **左右對照** 則同時顯示所有語言。每個欄位仍保留自己的語言小標籤：點擊只切換該欄位，把鼠標停在標籤上則可看到該欄位在那種語言的全文，不必切換。

## 開始使用

### 第一次登入

1. 在瀏覽器打開 Canon（辦公室電腦：`http://localhost:3000`；其他電腦使用 Canon 窗口顯示的地址，即辦公室電腦的網絡地址，例如 `http://192.168.1.20:3000`）。若路由器給電腦換了地址，窗口會顯示新的地址；負責電腦的同工可在路由器中為它保留固定地址。冒號後面的數字是端口：若要改用其他端口，可請負責電腦的同工在 `start-canon.bat` 旁邊建立 `canon.local.bat`，寫上一行例如 `set CANON_PORT=5018`。
2. 第一次會看到 **歡迎使用 Canon**。選擇 **聚會語言**（主要語言排第一），填寫 **教會名稱**、**顯示名稱**、**用戶名** 和 **密碼**（至少 8 個字符）。
3. 按 **創建管理員**。界面語言可在頂部切換為 **EN**、**簡體中文** 或 **繁體中文**。

### 語言與聖經

接著出現 **開始設置**：**模塊**（教會使用的 Canon 功能）、**Canon 自帶資料庫**，以及與 [設置 → 語言](/settings) 相同的畫面。

**Canon 自帶資料庫** 是可選的：勾選要加入的內容，再按 **加入資料庫**。不按就不會加入任何內容；其餘的之後可在 [資料庫](/library) → **Canon 自帶資料庫** 加入。

- **詩歌與詩篇**：約 380 首公共領域的詩歌、韻文詩篇與禮儀短歌，含英文歌詞與作者資料。
- **禮文**：信經、宣召、認罪文、禱文與祝福，中英文。
- **聚會模板**：五個使用這些詩歌與禮文的聚會次序。
- **威斯敏斯德信仰準則**：小要理問答、大要理問答與信仰告白（英文），從互聯網下載。

然後：

1. **聚會語言**：勾選教會使用的語言；第一個是主要語言。有 **UI** 標籤的語言，表示 Canon 本身的畫面也已譯成該語言（並顯示翻譯了多少，例如“UI 82%”），同工可用該語言使用 Canon；其他語言只用於聚會。任何人都可以不寫程序就新增或改進一種語言：請參閱 Canon 文件中的 `CONTRIBUTING-TRANSLATIONS.md`。
2. **聖經**：為每種語言按 **下載並導入**，取得公共領域的聖經（KJV、和合本等），並選擇 **默認譯本**。
3. **次序單與投影**：選擇 **默認印刷與投影的語言**（最多 3 種）和 **雙語排版**（**左右對照** 或 **上下排列**）。
4. 按 **完成設置**。

> **提示：** 有授權的譯本（ESV、和合本修訂版、新譯本等）之後可用 **＋ 添加聖經譯本** 上傳，詳見 [聖經](#聖經)。

### 教會資料與標誌

打開 [設置](/settings) → **教會**：教會名稱、**教會標誌**（**上傳標誌**：PNG、JPEG、WebP 或 SVG，最大 2 MB）、地址、**聯繫信息**（印在次序單上）、**CCLI 授權編號** 和 **默認開始時間**。按 **保存**。

### 一間教會，幾個堂 {#congregations}

如果一間教會有幾個堂（例如英文堂、華文堂、印尼堂），可在 **設置 → 教會 → 各堂** 按 **新增堂** 加入：名稱、標記用的 **簡稱**（EN、華、ID）、顏色，以及 **聚會所用語言**。之後：

- 聚會、聚會模板、會友和小組都可以在表單的 **所屬堂** 欄位標記所屬的堂；
- **聚會**、**會友**、**小組** 和事奉表會出現 **全部 · EN · 華 · ID** 篩選按鈕，並在這臺電腦上記住選擇；
- 某個堂的新聚會會預先選用該堂的語言；聚會模板也可以歸入某個堂，用它建立的聚會也歸入該堂。

只有一個堂的教會把列表留空即可，不會看到這些功能。刪除一個堂時，它的聚會、會友和小組都會保留，只是不再標記所屬堂。

### 添加同工帳戶

**設置 → 用戶帳戶 → 添加用戶**。每個帳戶都屬於一位教會會友：在 **會友** 中選擇（若名單中還沒有，請先在 [會友](/members) 中加入）。只有 **外部訪客** 帳戶不需要會友。設置 Canon 的管理員可以先不連結；在連結自己的帳戶之前，每頁上方都會有提醒（**連結我的帳戶**，或按 **稍後提醒** 至下次登入）。

選擇角色：
- **管理員**：所有功能，包括設置、帳戶和角色。
- **牧者 / 長老**：會友及其資料和備註、群組、聚會活動和主日聚會；可查看記錄和奉獻。
- **編輯**：策劃聚會，編輯名冊、資料庫、事奉表和記錄（與 0.13 之前相同）。
- **聚會策劃**：主日聚會、模板、資料庫和事奉表；會友只看姓名。
- **財務**：聚會記錄和奉獻——輸入、核實和重開現金點算；其餘只能查看。
- **文書**：名冊——會友、同工、群組、聚會活動和聚會記錄（不包括奉獻）。
- **只讀**：可查看和打印；不看奉獻、會友聯絡資料或備註。
- **圖書管理員** 和 **資產管理員**：只管理 [圖書館](#lending-library) 或 [資產登記](#asset-register)（教會開啟該功能時）。
- **外部訪客（只讀）**：供教會以外的人使用，例如審計員。可查看主日聚會、資料庫、聚會記錄和奉獻，不能更改任何內容，也絕不看會友聯絡資料或備註；不連結到會友。可以讓它查看更多（角色 → **編輯**），但不能讓它更改。

**設置 → 角色與權限**（管理員）顯示每個角色在 Canon 各部分的權限：**無權限**、**查看** 或 **編輯**，以及是否可查看會友的聯絡資料和備註、標為敏感的欄位，以及可否重開已核實的現金點算。每個角色的 **⋯** 菜單有 **編輯**（調整預設角色以配合教會；管理員始終擁有所有權限）、**複製**（以此角色的副本開始一個新角色，例如“秘書（不含財務）”）、**歸檔**（沒有帳戶使用的角色：保留，但新增帳戶或更改帳戶角色時不再提供；已歸檔的角色放在 **已歸檔的角色** 下，按 **還原** 可恢復），以及教會自己沒有帳戶使用的角色可 **刪除**。**新增角色** 可從頭加入，例如可編輯聚會和資料庫的敬拜主領。Canon 的預設角色可以歸檔，但不能刪除。角色無法查看的頁面不會出現在側邊欄；代表某人工作的 AI 助手也遵循同一個角色。看不到敏感欄位的角色也不能修改它們：會友表格上不會出現這些欄位，保存會友時它們保持不變。

**安全登入**：
- 連續輸入 5 次錯誤密碼，帳戶會鎖定 15 分鐘（列表顯示 **已鎖定**）；按 **重設密碼** 即可解鎖。
- **兩步登入**（設置 → 我的資料 → **設定兩步登入**）：用手機上的身份驗證應用（Google 或 Microsoft Authenticator、1Password 等）掃描二維碼，並輸入應用顯示的驗證碼。之後每次輸入密碼後，Canon 會要求輸入 6 位數驗證碼。請保存只顯示一次的 **恢復碼**：手機遺失時，每個恢復碼可登入一次。
- **重設兩步登入**（管理員，在用戶列表中）可為遺失手機的人關閉兩步登入。在安全與隱私中按 **要求管理員使用** 或 **要求所有人使用**，這些帳戶都必須使用兩步登入：未設定的帳戶登入後只會看到設定畫面，設定完成後才打開 Canon。

**限定於**（有幾個堂的教會）：限定於某個堂的帳戶，只看到該堂以及全教會的聚會、聚會活動、記錄、會友、群組和活動——看不到其他堂的資料；它新建的項目屬於該堂，報表也只關於該堂。代表它工作的 AI 助手同樣如此；經由其他項目看到的人（群組成員、輪值表、家庭）也一樣：其他堂的人不會顯示，也不能加入它的群組或輪值表。要把項目移到另一個堂，需要全教會的帳戶。成員全屬其他堂的家庭也不會顯示給它。管理員始終可以看到全部。
- **聚會帶領者**：把帳戶連結到所屬的會友（**會友** 一欄）。在群組中被勾選為 **帶領** 的會友，或被選為某次聚會 **帶領者** 的會友，就可以用那個帳戶（即使是隻讀帳戶）記錄那些聚會活動：人數、新朋友及其聯絡資料（以便跟進）、備註、奉獻及其現金點算和簽名、聚會的詳情和下一次聚會。其他方面不變：主日聚會、其他聚會活動和名冊仍是隻讀的；刪除聚會活動或重開已核實的點算，仍由編輯和管理員負責。

## 每週工作

側邊欄把頁面分組：**策劃**（主日聚會、聚會活動、資料庫和三種模板）、**會眾**（小組與團契、會友、同工、事奉）、**記錄** 和 **管理**。點擊部分的名稱可收起，再點一次即可展開；Canon 會在你的瀏覽器中記住這個設定；前往已收起部分中的頁面時，該部分會重新展開。

[概覽](/) 是首頁：下一堂聚會及其狀態、未來幾週尚未安排的崗位與衝突（把指針停在 ⚠ 或「崗位待排」標籤上，或在手機上輕點，就能看到詳情）、近期生日，以及次序單和投影的快捷入口。問候語會隨一天的時間和教會年曆（將臨期、聖誕期、復活期……）改變，主日和重要節期另有問候，偶爾還有驚喜——平安（Shalom）、唯獨榮耀歸於神、哈利路亞（大齋期不用）。底部是資料庫：詩歌和禮文的數目，以及每種語言已安裝的聖經譯本；點擊卡片會打開資料庫的相應部分。

[日曆](/calendar) 把主日聚會、聚會活動和教會其他活動放在一起：**月**、**周** 或 **列表**（接下來八週；手機上顯示為列表），可按堂（連同全教會的項目）和群組篩選。點擊主日聚會或聚會活動即可打開。**新增活動**（編輯）可加入教會日曆上的其他事項——營會、婚禮、清潔日等——填寫日期（持續幾天的活動填 **結束日期**）、時間、**場地**（教會的場地，已被預訂時會提醒）或地點、堂和群組；點擊活動可更改或刪除。

### 1. 策劃主日聚會

1. 進入 [聚會](/services)，按 **＋ 新建聚會**。
2. 確認 **日期**（默認為下一個主日），填寫 **經文**（例如 以賽亞書 6:1-8）和 **講題**。**講員** 來自事奉表（講道項目的帶領人）。
3. 選擇 **模板**（或 **空白程序**），再按 **新建聚會**，便會打開聚會程序。
4. 在聚會資料中選擇舉行的 **場地**（管理員先在 設置 → 場地 加入教會的場地）。若同一場地在同一時間已被其他聚會、聚會活動或活動預訂，會顯示提醒並列出它們；仍可保存，因為有時是刻意共用禮堂。

**聚會程序**

- 把鼠標移到兩個項目之間，按小小的 **＋**（**在此插入**），選擇類別（**詩歌**、**讀經**、**禮文**、**禱告**……），然後搜索，或選 **先加入空位，稍後填寫**。
- 也可以用右邊的資料庫面板（**詩歌與詩篇**、**信經與禮文**、**經文**、**程序元素**）：點擊即可加入，或把它拖進程序中。
- 每首詩歌都會顯示在本堂聚會之前 **上次** 何時唱過（或 **未唱過**）；如果在之前四周內唱過，會以醒目顏色標出，提醒你避免重複。
- 調整次序：拖動項目左邊的把手，或打開項目後按 **上移** / **下移**。
- 出現 **詩歌 ?** 或 **經文出處 ?** 標記，表示該空位還要填寫。

**編輯項目**：點擊項目即可，改動會自動保存。

- **詩歌**：選擇詩歌，勾選要唱的 **節數**（副歌會自動印出）。若一首詩歌收在幾本詩本中，可在 **詩本** 選擇顯示哪一本的編號。
- **讀經**：輸入 **經文出處**（`羅馬書 8:28-39`、`詩 23`、`約 3:16`）。每種語言可為這段經文另選 **聖經譯本**。
- **禮文**：選擇禮文。要理問答在 **問答** 輸入題號，例如 `1-3` 或 `Q4-6`；按 **下一組** 可跳到接下來的問答。
- **姿勢**：眾立或眾坐會印在次序單上。
- **印在次序單**：**依模板**、**完整內容**、**只印標題** 或 **不印出**。**顯示於投影** 決定是否投影該項目。
- **投影**（在 **顯示在投影** 旁邊）：**只顯示內容**（照常顯示文字）、**只顯示封面**——一張有項目名稱和負責人的投影，例如只顯示“三疊阿們”而不是三次阿們——或 **先封面，後內容**，例如在經文前先顯示“讀經 · 李路得”。PowerPoint 和 FreeShow 文件也一樣。
- **帶領** 只能選這堂聚會事奉表上的人——不能自行輸入名字。有 **崗位** 時，事奉表上該崗位的人全部勾選；取消勾選部分人，就只印所勾選的（例如兩位招待中的一位）。沒有崗位時，可從這堂聚會事奉表上的任何人中勾選（默認無人）。請先在 **事奉團隊** 中排人。0.15.10 之前輸入的名字，在未從事奉表選人前仍會印出；策劃頁會顯示為 **之前輸入**，並有 **移除** 按鈕。複製的聚會不會帶上輸入的名字。聚會的 **講員** 就是 **講道** 項目的帶領人（在該項目中選擇），不能自行輸入。
- **投影片上的二維碼與短句** 可在該項目的投影片上加二維碼或短句。
- **投影背景** 只在這個項目的投影片後面放一張圖片（例如聖餐的餅與杯），取代投影模板的背景。圖片從 **資料庫 → 投影背景** 中選擇（可輸入文字搜索）。圖片會用模板的背景色淡化，讓文字清楚易讀；PowerPoint 下載也會使用。

**聚會資料**：按程序上方的 **編輯…**，可更改日期、時間、語言（最多 3 種）、**聖經譯本**、**教會節期**、**次序單封面**、**次序單模板**、**投影主題** 和 **參考代碼**（你為這次聚會定的簡短代碼，例如 `EN-2026-12-25`）。改好後按該卡片中的 **保存**。

**參考代碼。** 聚會和三種模板都可以有 **參考代碼**：你自己定的簡短代碼（字母、數字和 - _ .，不可有空格，例如 `EN-001` 或 `CN-10pmService`），同一類中不可重複。它會顯示為小標籤，可代替名稱使用——同工和 AI 助手都可以，例如“用模板 CN-10pmService 建立下主日的聚會”。在聚會資料、聚會模板編輯器中設定，投影或次序單模板則在 **⋯** 菜單按 **設定參考代碼…**。

程序準備好後，把頂部的 **草稿** 切換為 **定稿**。

> **提示：** 在 **輸出** 欄末端的 **⋯** 菜單中，**複製** 可把整個程序複製到另一個日期（可連同事奉名單），**另存為模板** 可把滿意的程序存成模板；**刪除這次聚會** 也在那裡。

### 2. 事奉安排與提醒

打開 **事奉團隊** 分頁。

1. 在每個崗位下按 **＋ 添加** 選人（**可事奉崗位** 列出平常事奉這個崗位的人；外出的人會有標記）。
2. 點擊名字可切換狀態：**已安排 → 已確認 → 已婉拒**。按 **×** 移除。
3. 查看 **提醒** 欄：未排滿的崗位、重複安排、外出的人。
4. 按 **發送提醒**：勾選 **收件人**，需要時加上 **附註**，查看 **預覽**，再按 **發送給 N** → **立即發送**。

> **提示：** 系統絕不會自動發送電郵，電郵發出後也無法收回。若想在電郵中附上聚會程序，請先啟用分享鏈接。須先在 設置 → **電郵** 完成設定。

### 3. 打印次序單

**本週家訊**：打開程序策劃頁的 **次序單** 分頁（在 **聚會程序** 和 **事奉團隊** 旁邊）。這裡列出該聚會所用次序單模板的每週內容：先是 **報告事項**（家訊），然後是 **牧者的話** 等每週內容。每種語言分別輸入，會自動保存。**有編號的行會印成列表。** 程序中的 **報告** 項目仍保留為有時間的項目，但它的內容現在印在報告事項部分。以前把家訊寫在該項目裡的聚會，會預先填好內容並顯示 **請保存以保留**。若分頁顯示 **這個模板沒有每週內容**，請在模板的頁面編排中加入 **報告事項** 或 **每週內容**。

1. 在程序的 **輸出** 欄按 **次序單**。
2. 選擇 **模板**、**紙張**（通常是 **A4 橫向對摺（A5 小冊）**）、語言、排版和 **字號**。
3. 按 **打印**。

> **提示：** 小冊子要 **雙面打印，短邊翻頁，然後對摺。** 對摺小冊子的頁數必須是 4 的倍數：若顯示「共 5 頁——將加入 3 個空白頁，以便對摺成小冊子（共 8 頁）」，空白頁會加在封底前面。若提示內容超出一頁，請縮小字號，或把較長的項目改為只印標題。

### 4. 投影

1. 在 **輸出** 欄按 **投影片**，會在新分頁打開；把該分頁拖到投影屏幕，按 **F** 全屏。
2. 按 **打開主控窗口** 在自己的屏幕上顯示當前與下一張投影片、備註和時鐘。兩個窗口必須在同一臺電腦的同一個瀏覽器裡。

| 按鍵 | 作用 |
|---|---|
| → / 空格 / Enter | 下一張 |
| ← / Backspace | 上一張 |
| **B** | 黑屏 / 恢復 |
| **W** | 清除文字（只留背景） |
| **F** | 全屏 |
| **O** | 總覽所有投影片 |
| 數字 + Enter | 跳到該張 |

**輸出** 欄的 **文件** → **PowerPoint 幻燈片** 會把投影片下載為 PowerPoint 文件，方便在沒有 Canon 的電腦上使用，或發給音控同工。文件沿用該聚會的幻燈片模板（顏色、背景圖片、字體、字號、每張行數、頁腳和屏幕比例）；**自定義 CSS** 不會帶過去。用 PowerPoint 打開後按 **F5** 放映。各語言的文字使用模板字體中 Windows 電腦有的第一個（否則用 Georgia、宋體 SimSun 或微軟正黑體）。

在 Mac 上請選擇 **文件** → **PowerPoint 幻燈片（Mac 的 Keynote）**：同樣的投影片，使用每臺 Mac 都有的字體（宋體 Songti、蘋方 PingFang、Helvetica Neue 等）。用 Keynote 打開（**文件 → 打開**）後按 **播放**；**文件 → 存儲為** 可存成 Keynote 文件。

**核准**（在 **輸出** 欄；可編輯該聚會的人都可使用）：保存次序單和投影目前的副本——文字、次序、人員、次序單模板和幻燈片模板——連同日期、核准人和可選的備註。之後按鈕會顯示 **已核准**，聚會更改後則顯示 **核准後已更改**。**已核准的版本** 列出所有版本；按其旁邊的 **次序單** 或 **投影片**，即可按核准時的原樣打開那個版本（頂部有綠色提示），即使聚會之後已更改。圖片只是引用，不會複製。

### 5. 與事奉團隊分享

- **流程表**：可打印的時間流程，列出帶領者和影音提示。**投影片** 欄列出每項的投影片編號，影音提示註明每部分從第幾張開始——例如每節後都唱副歌的詩歌：“1 → 3 · 2 → 6 · 3 → 9 · 副歌 → 5, 8, 11”，以及二維碼或短句投影。編號與投影片頁腳的編號相同，操作員可輸入編號再按 Enter 跳過去。編號以標題投影為第 1 張，按聚會目前的內容計算：內容更改後請重新打印。
- **樂譜**：按次序列出聚會的詩歌、要唱的節數，以及資料庫中每首詩歌的樂譜（見 [資料庫](#資料庫)）——可打印，或在鋼琴旁用平板打開。沒有樂譜的詩歌也會列出，樂手便知道要自備；PDF 會另行打開。
- **分享**（在 **輸出** 欄；有鏈接生效時顯示 **開啟**）有兩個鏈接：
  - **分享給團隊**：按 **啟用鏈接**，再按 **複製** 把鏈接發給大家。鏈接只讀，不含聯繫方式。除了聚會程序，還列出只有團隊需要的內容：聚會的 **備註**（在最上方，標題為 **給事奉團隊的備註**）、各項目的備註（在該項目下方）、今日事奉同工，以及下一堂聚會的服事人員。**停用鏈接** 後舊鏈接失效；重新啟用會產生新鏈接。
  - **給會眾的次序單**：每堂聚會一個鏈接，讓會眾在手機上看次序單——聚會程序、詩歌和經文、報告事項，可切換語言；不含事奉同工、團隊備註或聯繫方式。可勾選 **在次序單封底印出二維碼** 和／或 **在標題投影角落顯示二維碼（會眾進場時）**——聚會開始前顯示的那一張，適用於 Canon 投影和 PowerPoint 文件（FreeShow 項目則作為第一個節目），或按 **下載二維碼** 用在別處。**停用鏈接** 後鏈接失效。
  - 兩個鏈接（以及新朋友表格、寄給團隊的電郵和二維碼標籤）都使用教會的 **公開網址**（設置 → AI / MCP）。沒有公開網址時，會使用這臺電腦在教會網絡上的地址，絕不用“localhost”或電腦名稱，因此只能在教會自己的網絡中打開。
- **文件** → **PowerPoint 幻燈片**、**Word 文件** 和 **FreeShow 項目** 可下載給其他軟件使用。
- **在手機或較窄的窗口上**，次序單、流程表、樂譜、新朋友卡、現金點算聲明和標籤會縮小顯示，讓整頁符合屏幕寬度；打印時仍是實際大小。
- 連接 Canon 的 AI 助手也可以為這些文件生成 **下載鏈接**（約一天後失效）。持有鏈接的人無需登錄即可下載該文件，請只發給需要的人。
- **電郵事奉團隊** 會用你自己的電郵軟件打開新郵件，團隊成員放在密件副本。

## 聚會活動 {#meetings}

[聚會活動](/meetings)（側邊欄 **策劃** 之下）包括團契聚會、小組、禱告會、主日學班、委員會會議和單次聚會——比主日聚會簡單，有自己的記錄。

### 策劃聚會活動

- **新建聚會活動**：選擇群組和日期。群組的新聚會會複製上一次的聚會（時間、地點、帶領者、是否收奉獻）；第一次會用群組的名稱。單次聚會請選擇 **不屬於群組**，並填寫標題。
- 聚會頁面上有：**標題**、**日期**、**開始時間**、**場地**（教會的場地；下一次聚會會沿用，重複預訂會顯示提醒）或 **地點**（其他地方，例如家中）、**帶領者**（會友；不在名冊中的人可改為輸入姓名）、**經文**、**主題** 和備註。**下一次聚會** 會把這次聚會複製到另一個日期（默認一週後）。

### 奉獻與新朋友表格

- **這次聚會收奉獻**：每次聚會各自開關（下一次會沿用）。收奉獻時，記錄中有現金點算、點算聲明和簽名，與主日聚會相同；不收奉獻時，只有人數、新朋友和備註，這次聚會也不計入奉獻報表。
- **新朋友可用手機填寫表格**：與主日聚會相同的新朋友表格（須先在 設置 → 新朋友表格 開啟）。勾選後，這次聚會活動會有自己的二維碼和鏈接，並可 **打印卡片**；填寫的資料會在下方等你 **接受** 後加入這次聚會活動的記錄。聚會活動的帶領者也可以這樣做。

### 記錄聚會活動

**記錄這次聚會** 會打開它的記錄。聚會程序、次序單和投影都是可選的（**新增聚會程序**）。

群組的帶領者可以用自己的帳戶（即使是隻讀帳戶）記錄群組的聚會活動：管理員把帳戶連結到所屬的會友（設置 → 用戶帳戶），群組再勾選誰是 **帶領**（見 [會眾](#people)）。聚會活動本身的 **帶領者** 也可以記錄。

### 定期聚會

**聚會規律**（在 **編輯群組** 中）：**每週**、**每兩週** 或 **每月一次**（第一個……第四個或最後一個星期幾），以及 **開始時間** 和 **地點**。**預先建立聚會** 會每天建立那麼多周之內的聚會（0 = 只在你按群組中的 **預先建立聚會** 時建立），每次都複製上一次，帶領者只需打開當晚的聚會。個別聚會仍可單獨更改日期或刪除。

## 資料庫

打開 [資料庫](/library)。

### 詩歌與詩本

- **詩歌**：可按標題、歌詞或編號（`HP 123`）搜索。**新建詩歌**：標題、作者、曲調、詩節（副歌的標籤寫 `R`）、**詩本編號**。取消勾選 **公共領域** 即可填寫版權和 **CCLI 詩歌編號**。
  - **每節後都唱的副歌**：只輸入一次，作為標籤為 `R`（或合唱用 `C`）的詩節，並勾選 **每節後唱副歌**。在聚會中只勾選要唱的數字詩節，Canon 會在每節後加上副歌。投影片每次都完整顯示副歌；次序單第一次完整印出，之後各節後只印“（副歌）”。投影上，每一節（或副歌）的每一張投影上角都會顯示節數（或“副歌”），不只是第一張。
  - **樂譜**：按 **新增頁面** 加入樂譜的掃描或照片（PNG、JPEG 或 WebP）或 PDF，每個最大 10 MB；用箭頭調整頁序。有樂譜的詩歌在列表中顯示 ♫ 和頁數。樂手可在聚會策劃的 **輸出 → 樂譜** 找到。樂譜只留在 Canon 內（及其備份中）：不會出現在分享頁或投影片；只有在管理員提供時（設置 → AI / MCP），AI 助手才能閱讀。只保存教會可以複印的樂譜（公共領域，或在教會的版權許可之內）。
    - **用手機**：顯示一個二維碼。用手機掃描後逐頁拍下詩本（或選擇文件），就會成為這首詩歌的下一頁，無需登入。鏈接有效 24 小時。
    - **上傳樂譜**（列表上方）：一次上傳多個掃描文件。請以詩本編號為文件命名，例如 `HP 178.jpg`，第二頁為 `HP 178-2.jpg`（只寫 `178.jpg` 時使用第一本有這個編號的詩本）。Canon 會把文件配對到詩歌；請檢查列表，可更改或略過，選擇是否 **取代** 原有頁面，然後上傳。
- **Canon 自帶資料庫**（管理員，在 詩歌 與 禮文 分頁）可加入 Canon 自帶的公共領域詩歌與詩篇、禮文、聚會模板和威斯敏斯德信仰準則，與設置 Canon 時的選擇相同。每一部分都會顯示資料庫中已有多少。詩歌含英文歌詞、作者、曲調與格律；少數註明其常用曲調或和聲仍有版權，但歌詞本身可自由印刷與投影。您可以在詩節中加上中文歌詞，或刪除不用的項目：刪除的項目在 Canon 更新後不會再出現。勾選 **也加回刪除過的項目** 即可加回。
- **詩本**：**新增詩本** 並填寫 **縮寫**（顯示在編號前，如 HP 123）。排第一的詩本是默認編號。
- 要導入詩本目錄（編號與標題），在該詩本使用 **導入 CSV…**。資料庫中沒有的詩歌會以“只有標題”的方式加入，並加上 needs-words 標籤；歌詞絕不會被導入。

> **提示：** 有版權的歌詞，只能在教會持有授權的情況下輸入。

### 禮文與要理問答

- **新建禮文**：選擇類別（宣召、認罪、信經、要理問答……）。啟應文每行以 `L:`（領）、`C:`（會眾）或 `A:`（齊）開頭；空一行表示新段落或新投影片。
- **分為編號部分** 可把長篇禮文分成編號部分（例如問答）。要理問答第一行是 `L: 問題`，第二行是 `C: 答案`。
- **導入威斯敏斯德信仰準則**（管理員）會加入小要理問答、大要理問答和信條（英文）。

### 聖經

- 資料庫 → **聖經**：輸入 **經文出處** 或 **搜索** 字詞；**＋ 對照** 最多可並排 4 個譯本。
- 添加有授權的譯本：**設置 → 語言 → ＋ 添加聖經譯本**。下載 CSV 模板（`book, chapter, verse, text`），在 Excel 另存為 **CSV UTF-8**，勾選授權確認，檢查預覽後導入。
  - **許可與可用範圍**（管理員）：已安裝譯本旁的鎖形按鈕可記錄其 **版本**、**許可** 文字以及可用於哪些用途——**印刷**（週報、Word 文件）、**投影**（幻燈片、演示文件、FreeShow）和 **網上**（公開分享頁面）。新上傳的譯本可以印刷和投影，但在勾選 **網上** 之前不會放到網上；公版譯本全部允許。不允許的用途，該輸出只顯示經文出處而不顯示經文，聚會編排頁面會在程序上方提醒（**聖經許可**），以便改選其他譯本或貼上獲許可的經文。重新上傳同一譯本會保留已記錄的設定。
  - **印尼文**：Canon 沒有附帶印尼文聖經。常用的譯本（Terjemahan Baru，以及較早的 Terjemahan Lama）由印尼聖經公會（Lembaga Alkitab Indonesia）持有權利，教會須取得聖經公會許可後自行上傳所用的譯本。

### 二維碼與短句

**二維碼與短句** 可建立 **新二維碼**、**新圖片** 和 **新短句**，用在次序單封底和投影片上（例如奉獻鏈接或 Wi-Fi）。

### 檢查資料庫

**檢查資料庫**（在詩歌、禮文和聖經分頁）列出各語言內容不一致的詩歌和禮文——某一節或某部分只有一種語言、行數或段落數不同、領會／會眾的行次序不同——以及可能重複的項目（標題相同、同一詩本編號用了兩次），還有某章經文比其他譯本少的聖經譯本（通常是節數編排不同，有時是缺少整卷書）。標為 **檢查** 的通常需要修正；標為 **備註** 的可能沒問題。AI 助手可以和你一起處理（**check_library** 工作步驟）。

### 投影背景

**資料庫 → 投影背景** 保存用於單個聚會項目投影片的全屏圖片。按 **新增背景…** 上傳 PNG、JPEG 或 WebP（最大 10 MB）；每張圖片會顯示尺寸（比屏幕小時會提醒：寬屏投影機用 1920 × 1080，4:3 用 1440 × 1080），以及有幾個項目使用。可 **改名**、**替換**（所有使用它的項目都會換成新圖片）或刪除；使用已刪除背景的項目會改回模板的背景。

## 模板

Canon 有三種模板：**聚會模板** 是建立聚會時的程序起點；**次序單模板** 決定印出的次序單包括什麼、樣子如何；**投影模板** 決定投影片的樣子。三者都在側邊欄的 **策劃** 之下。

### 聚會模板 {#service-templates}

[聚會模板](/templates) 是可重複使用的聚會程序：按次序排列的項目，連同時長、崗位和姿勢。詩歌和讀經的位置留空，每週再填寫。

1. 按 **新建模板**——或在滿意的聚會中，打開 **輸出** 欄的 **⋯** 並選擇 **另存為模板**。存成模板的聚會會保留項目、投影模板、次序單模板和所屬堂。
2. 填寫 **模板名稱**（各種語言）和 **說明**，設定 **開始時間**，再按 **添加項目** 加入詩歌、讀經、禮文、講道等，每項填寫時長和 **崗位**（由誰帶領）。要理問答或其他分部分的禮文可用 **問答**（或 **部分**）選擇用哪些，如 `1-4`；詩歌可用 **節數** 只選部分詩節（留空 = 全部）。用模板建立的聚會會從這些開始。
3. 若與教會默認不同，可選擇它的 **投影模板** 和 **次序單模板**：用它建立的聚會會先用這些模板（每次聚會仍可另選），例如晚堂中文聚會模板會帶出自己的次序單和投影。
4. 按 **使用模板** 即可用它建立新聚會。聚會頁面的 **新建聚會** 也會列出這些模板。

卡片的 **⋯** 菜單有 **設為教會默認**（管理員：**新建聚會** 時預先選好的模板，會顯示 **教會默認** 標記）和 **歸檔**（移到頁面底部的 **已歸檔的模板**）。三種模板的歸檔和刪除規則都一樣——見下文。

### 模板一覽

次序單模板和投影模板都先顯示模板一覽。每張卡片有一個主要按鈕（自己的模板是 **編輯**，內置模板是 **預覽**）和 **⋯** 菜單：

- **設為教會默認**（管理員）：聚會若沒有另選模板，就會使用這個模板。
- **複製一份來修改** / **複製**：Canon 自帶的內置模板不能修改或刪除，請複製一份再修改副本。
- **歸檔**：模板不再出現在聚會策劃的列表中（已使用它的聚會不受影響）。已歸檔的模板在頁面底部的 **已歸檔的模板** 中，按 **恢復** 即可再用。教會默認模板不能歸檔；把已歸檔的模板設為教會默認會自動恢復它。
- **導出為文件**：把模板存成一個文件（連同背景圖片，或頁面要印的二維碼和圖片），可複製到另一臺電腦或與其他教會分享。在頁面頂部按 **導入模板文件…** 會把它加為新模板；所需的二維碼與短句若資料庫中沒有同名的，會自動加入。
- **刪除**（管理員）：只能刪除已歸檔的模板，Canon 內置的模板永遠不能刪除（只能歸檔）。請先歸檔，再在 **已歸檔的模板** 中刪除。使用已刪除的投影或次序單模板的聚會會改用教會默認模板；用已刪除的聚會模板建立的聚會仍保留原有程序。

編輯頁把設定分成可展開的編號步驟，旁邊是大的即時預覽。修改會立即顯示在預覽中；按底部欄的 **保存修改** 保留，按 **放棄** 取消。把鼠標移到 **?** 可看簡短說明，按 **使用說明** 會回到這裡。

### 次序單模板 {#bulletin-templates}

[次序單模板](/bulletin-templates) 決定印出的次序單包含什麼。**即時預覽** 會逐頁顯示示例聚會。

1. **紙張與語言**：紙張（通常是 A4 橫向對摺成 A5 小冊子）、字號、印全部語言或只印主要語言、並排或先後排列。
2. **要印出的內容**：各類項目印全部內容、只印第一節，或只印標題／經文出處。
3. **封面與聚會程序**：封面樣式、橫幅顏色、列表或表格、詩歌編號、姿勢、帶領者和時間。
4. **頁面編排**：按印刷次序排列的各部分：**封面或橫幅**、**聚會程序**、**全部內容**（信經、要理問答和詩歌集中印在程序之後）、**報告事項**、**每週內容**、**固定內容**、**今日事奉**、**下週服事**、粗體 **短句**、**二維碼、圖片與短訊**、**講道筆記頁**，以及 **版權聲明與教會聯絡資料**。**講道筆記** 可選 **獨立一頁**、**前一部分下方的餘下版面**（例如在報告事項下方印出橫線，讓會友自己記筆記）或 **只在對摺小冊子的空白頁**。拖動部分（或用 ↑ ↓）調整次序；用 **加入部分 ▾** 和 **加入分頁** 增加內容。
   - 每個部分都可以 **另起一頁**、**保持在同一頁**，或 **放在封底**。封底總是印在最後一頁（對摺小冊子的空白頁會加在它前面）。
   - **固定內容**（歡迎詞、教會異象、奉獻資料）每週相同，在模板中輸入；**每週內容**（牧者的話、代禱事項）和 **報告事項** 在每次聚會的 **次序單** 分頁輸入。

### 投影模板 {#slide-templates}

[投影模板](/slide-templates) 決定投影和 **PowerPoint 幻燈片** 下載的樣子。預覽顯示標題頁、詩歌、讀經和啟應文，點選任何一張可放大查看。

1. **顏色與背景**：深色或淺色起點、四種顏色、背景圖片及淡化程度。
2. **字體與字號**：先勾選 **此模板的語言**；然後每種語言各有 **字體**（只能用投影電腦上已安裝的字體；同一種文字的語言，例如英文和馬來文，共用字體）和相對於其他語言的 **大小**——同樣字號時中文看起來比英文小，例如設為 115% 就能平衡（較長的內容仍會縮小以符合畫面；PowerPoint 下載也用同樣的大小）。接著是整體字號、行距和對齊。
3. **每張投影片的內容**：**每張投影的行數**（默認：顯示兩種或以上語言時每種語言 2 行，只有一種語言時 3 行；經文、信經與禱文中一行即一句；一句可以跨越信經或禱文的好幾行，在投影上仍保留原來的換行）。**每張投影字號相同** 讓整場聚會的字體大小保持一致。
4. **屏幕比例與頁腳**：**寬屏 16:9**（大多數投影機和電視）或 **標準 4:3**（較舊、較方的投影機）；頁腳的經文出處、教會名稱和頁碼；姿勢提示；**標題投影上的二維碼**（次序單鏈接）：放在哪個角落、大小——**小**、**中** 或 **大**（PowerPoint 下載也按同樣方式放置）；以及 **最後一項之後加一張結束投影**，含各語言的 **結束語**（默認“感謝您與我們一同敬拜”）和教會名稱。某一週若要不同的話，可在那堂聚會的最後加一個項目。
5. **自定義 CSS（進階）** 可不理會，也不會套用到 PowerPoint 下載。

> **提示：** FreeShow 的屏幕比例在它自己的輸出設定中設定，所以 FreeShow 項目不跟隨模板的屏幕比例。

## 會眾 {#people}

- [小組與團契](/groups)：委員會、團契、小組、事工和 **事奉團隊**。**新增群組**，再 **添加成員**，填寫 **職務** 和任期。要保留記錄，請填寫結束日期或取消勾選 **使用中**，而不是刪除。
  - 每個事奉團隊同時也是一個 **事奉團隊** 群組：群組成員就是團隊名單，可像其他群組一樣填寫職務（**Leader／組長** 即團隊負責人）和任期。團隊在 **事奉** 頁面新增、改名和刪除，崗位也在那裡設定；在任何一處改名，兩邊都會一起更新。
  - **帶領**：勾選帶領這個群組的人（加入時職務為 **組長**、**主席** 或 **老師** 的人會自動勾選）。帶領者可以記錄群組的聚會——見 [聚會活動](#meetings)。
  - **主日學班** 也是一種群組：老師帶領，學生是成員，**年齡** 填寫學生的年齡範圍。
- [會友](/members)：**添加會友**，填寫姓名、**中文名**、**稱謂**（弟兄、姐妹、Bro.、Sis.、Rev.……）、聯繫方式、狀態、受洗與入會日期、家庭，以及 **其他資料** 中教會自己的欄位（見下文）。**生日** 分頁列出近期生日。“是／否”或“選擇”類的欄位可用來篩選列表（**所有會友** ▾）。只讀帳戶看得到姓名、家庭、小組和生日（月日），但看不到聯繫方式、備註、年齡或敏感欄位。
  - **會友的個人資料（PDPA）**——管理員在會友頁面：**個人資料** 會下載 Canon 保存的該會友所有資料（個人資料、家庭、小組、團隊、事奉、不在期間、同工記錄、帳戶、寄出的電郵、誰查看過資料、修改記錄，以及聚會上打字寫下其姓名之處），可交給本人。**刪除…** 在本人要求時刪除這些資料：須輸入其姓名確認。姓名、聯繫方式、日期、備註和教會欄位會永久清除；資格、團隊名額、不在期間、同工記錄和日後的事奉會被移除；帳戶取消連結；修改記錄（連同歸檔）也不再保留其資料。過去的輪值表和小組記錄保留匿名的“(erased)”，統計仍然準確。聚會和奉獻記錄上打字寫下的姓名（講員、點算人、簽名）作為教會記錄保留。備份中的副本會保留到該備份被刪除為止。
- [同工](/coworkers)：牧師、長老、執事和同工。**添加同工**，選擇人員、**職分 / 職位** 和 **類別**。**加入委員會…** 可標明所屬委員會。
- [事奉](/volunteers)：
  - **團隊與崗位**：**添加團隊**，**添加崗位** 並設定 **每堂所需人數** 和 **合資格人員**。被設為某崗位合資格的人會自動加入該團隊的名單（事奉團隊群組）。
  - **事奉表**：選擇期間，按 **自動編排** 公平地填補空缺，點擊名字更改狀態，**打印**。
  - **不便事奉**：為外出的人 **登記不便日期**，自動編排會跳過他們。

## 從 Excel 導入

大多數名單都有 **下載模板**、**導出** 和 **導入 CSV…**。

1. 按 **下載模板**，在 Excel 填寫。
2. 用 **另存為 → CSV UTF-8（逗號分隔）** 保存。
3. 按 **導入 CSV…** 選擇文件。此時尚未保存：預覽會顯示 **新增**、**將更新**、**沒有變動** 和 **有問題** 的行。
4. 按 **導入 N 行**，或 **導入有效的行並跳過錯誤**。

> **提示：** 同一個文件導入兩次也沒問題：已有的記錄會被比對並更新，不會重複。

導出和導入與畫面一樣遵循帳戶的權限：限定於某個堂的帳戶只會導出、預覽和更新該堂（以及全教會）的人；看不到敏感會友欄位的角色不會有這些欄位——它導入的文件中若有這類欄位會被忽略，已保存的值保持不變。

## 聚會記錄 {#service-records}

[聚會記錄](/records)（側邊欄 **記錄** 之下）保存每次聚會的情況：出席人數、新朋友、給同工的備註和奉獻。列表顯示最近 8 周、6 個月或 12 個月（若教會有幾個堂，也可按堂篩選），並顯示平均出席人數、新朋友人數和奉獻總額。點選某次聚會即可打開它的記錄。**聚會 / 聚會活動** 可在主日聚會和群組的聚會活動之間切換（見 [聚會活動](/meetings)），所以小組的人數不會拉低主日的平均出席；不收奉獻的聚會活動顯示 **不收奉獻**。

- **出席**：**出席人數**（成人和兒童）、**其中兒童**，如有直播則填 **線上** 人數。
- **新朋友**：姓名、聯絡資料、**如何來到**、**跟進同工**、**跟進**（新朋友、已聯絡、再來、已加入教會）和備註。新朋友的資料屬個人資料：只記錄教會跟進所需的資料。
- **給同工的備註**：做得好的地方、要改進的地方、代禱事項。
- **奉獻**：每個奉獻項目和方式一行（現金、支票、銀行轉賬、PayNow、刷卡），並按方式顯示小計。管理員在 **設置 → 奉獻** 設定貨幣和奉獻項目。
- **其他貨幣**：若收到其他貨幣的奉獻（例如新幣教會收到一張美元紙幣），把那一行的 **貨幣** 改為該貨幣（選 **其他…** 可輸入任何三個字母的代碼，例如 THB）。每種貨幣分別合計，不作兌換：列表和總額顯示教會的貨幣，其他貨幣列在下面（“+ USD 20.00”）。
- **現金點算**：輸入每種紙幣和硬幣的數量，Canon 會自動加總，並顯示與現金奉獻的差額。其他貨幣的現金另有點算（**USD 現金**；Canon 沒有面額的貨幣則直接輸入 **點算總額**），並可選填 **兌換後價值**（摺合教會貨幣，供司庫參考，不計入總額）。每種貨幣的點算都必須與它的現金奉獻相符。
- **點算簽名方式**：管理員在 **設置 → 奉獻** 選擇點算同工如何簽名，以及 **最少點算人數**（默認 2 人；更多人一起點算和簽名也可以）：
  - **紙本簽名**（默認）：填寫至少達到最少人數的 **點算同工** 和 **點算日期**（從日曆中選擇；留空則使用聚會日期），打印聲明讓他們簽名——姓名和日期已印好——再按 **標記為已點算並確認**。
  - **屏幕簽名**：每種貨幣的點算都相符後，每位點算同工輸入姓名，用手指、觸控筆或鼠標在記錄上簽名（**簽名確認點算**）。簽名人數不限。所有人簽好後（至少達到最少人數），按 **完成——所有點算同工已簽名** 確認點算。簽名只對應那一次現金點算：若管理員重新開啟點算，或在完成前現金有改動，簽名會被清除，點算同工需要重新簽名。
  - **點算同工以本人帳戶核准**（配合 **屏幕簽名**）：每位點算同工不畫簽名，而是以本人的 Canon 帳戶登入，按 **以我的帳戶核准**。在同一部設備上輪流畫的簽名，無法證明是不同的人點算；不同帳戶的核準則可以，所以開啟這項設定後，只有這種核准計入最少人數。記錄和點算聲明都會顯示每位同工的簽名方式。

  確認之後，現金對所有人都鎖定：現金奉獻行、點算的紙幣硬幣、點算同工和日期。其他方式的奉獻仍可加入——例如之後才收到的銀行轉賬。如需更正現金，由管理員按 **重新開啟現金點算**，修改後再次確認（或簽名）。出席人數、新朋友和備註仍可更新。
- **刪除**：有記錄的聚會不能刪除，以免出席和奉獻資料意外丟失。若記錄輸入錯誤，管理員可在記錄頁按 **刪除記錄**（已確認的點算須先重新開啟）；修改記錄會保留一份副本，奉獻資料完整保存。
- **打印現金點算聲明** 會打印一頁 A4：點算明細（每種貨幣分開）、按方式的總額、簡短聲明，以及點算同工的簽名——屏幕上籤的簽名，或紙本簽名用的空白姓名、簽名和日期欄。使用屏幕簽名的教會，在還沒有人簽名之前，也可以打印空白欄作為備用。

只讀用戶只能看到出席人數和備註，看不到奉獻和新朋友的聯絡資料。每項修改都記在 **設置 → 修改記錄**（管理員在記錄上按 **修改記錄** 可只看這次聚會的修改）。

## 新朋友表格 {#visitor-form}

新朋友可用手機填寫一份簡短表格，讓教會知道他們來過：**姓名**、**電話或電郵**（可不填）、**哪一項最適合形容您？**（可不填——例如慕道友、已信主未受洗、已受洗的基督徒、路過或旅行中、尋找教會）、**您怎樣知道這個聚會？**（可不填——例如親友邀請、路過、社交媒體，或 **其他** 並自行填寫）、**我希望教會有人與我聯絡**，以及（若教會提供）**代禱事項**（可不填）。留下聯絡資料或代禱事項時，必須勾選同意教會保存這些資料。

1. 管理員在 **設置 → 新朋友表格** 中開啟，並可更改 **歡迎詞**、**同意聲明**、**哪一項最適合形容您？** 的選項（全部刪除即不問這一題）和 **您怎樣知道這個聚會？** 的選項、是否提供代禱事項欄，以及聚會後幾天內仍接受填寫（從聚會前一天開始）。所選的答案會以教會的第一語言保存，讓新朋友報表把相同的答案合計在一起；同工在記錄中填寫 **如何來到** 時也會看到這些選項作為建議。
2. 在聚會的 **新朋友表格** 分頁為這次聚會開啟表格，並選擇二維碼出現在哪裡：**在次序單封底印出二維碼**、**在報告事項之後的投影片顯示二維碼**，或 **打印卡片**（每張 A4 八張，放在招待處或座位上）——可選其一或全部。
3. 提交的資料不會直接加入記錄，而是在 **待審核的新朋友卡** 中等候（在聚會的新朋友表格分頁和聚會記錄中都看得到；記錄列表會顯示等候的數目）。按 **接受** 會把新朋友加入這次聚會的 **新朋友** 名單（註明“via visitor form”，並附上代禱事項）；按 **捨棄** 可刪除垃圾或重複資料。

這份表格是公開網頁：任何人只要有聚會的鏈接或二維碼，不用登入就能打開，所以手機必須連得到 Canon——請在 設置 → AI / MCP 設定 **公開網址**。沒有公開網址時，鏈接會使用這臺電腦在教會網絡上的地址，只能在教會網絡中使用（若這臺電腦沒有網絡地址，分頁會提醒你手機無法打開）。網頁只顯示教會名稱和聚會的名稱與日期，不含任何程序碼，並會拒絕填寫太快、同一地方提交太多次或不在開放日子內的資料。聯絡資料、代禱事項和新朋友如何形容自己都屬個人資料（PDPA）：只讀用戶看不到；AI 助手只在 設置 → AI / MCP 的 **新朋友** 設為 **含聯絡資料** 時才看得到；新朋友報表只顯示每個答案的人數（**他們是誰**，只限編輯和管理員）。同一個地方（例如教會的 Wi-Fi，所有手機共用一個網絡地址）10 分鐘內最多可提交 40 份。

## 報表 {#reports}

[報表](/reports)（側邊欄 **記錄** 之下）彙總一段期間：選擇 **最近 3 / 6 / 12 個月**、**今年**、**去年** 或 **自選日期…**；若教會有幾個堂，也可選擇某個堂。除非選擇 **聚會活動**（以及某個群組或 **所有群組**），報表只計算主日聚會；事奉和會友統計始終是關於主日聚會和會友的。**打印** 會打印畫面上的報表；每個表格的 **CSV** 按鈕可下載給 Excel 使用。

- **出席**：平均出席、去年同期（及增減百分比）、最高的一次、兒童和網上人數、每次聚會的圖表（虛線為四周平均），以及每月和每個堂的平均。
- **奉獻**（編輯和管理員）：按奉獻項目和月份、按奉獻方式的總額（教會的貨幣）；其他貨幣分開列出，不作兌換；尚未確認的現金點算及已等候的天數。**給司庫的每月彙總** 打開某個月的一頁 A4：按項目和方式的總額、每次聚會及其現金點算、其他貨幣，以及簽名欄。
- **新朋友**：來了多少人，其中多少人已聯絡、再來、加入教會（在每次聚會記錄的 **跟進** 中設定），他們怎樣來到教會，以及每月人數。這些數字是按聚會記錄中的條目計算的：同一個人在兩次聚會都被記錄，就算兩次，因為 Canon 不會把不同聚會的新朋友連起來。只讀用戶只看到姓名。
- **事奉**：每人事奉（及婉拒）的次數、沒有被安排的團隊成員，以及 **難以安排的崗位**——某些聚會人手不足，或合資格的人太少。
- **詩歌**：每首詩歌唱過幾次、版權和 CCLI 編號（可導出作版權使用報告），以及期間沒有唱過的詩歌。
- **經文**：聖經每卷每章排成小方格——聚會中讀過的章為藍色，講道講過的章為金色，兩者都有的一半一半，次數越多顏色越深。點選方格可看日期。可選擇一個或多個 **年份**（不必相連，例如 2023 和 2025）代替期間；勾選 **只顯示有讀經或講道的書卷** 可縮短列表。總數顯示教會已讀過或講過聖經（及新舊約各自）的多少，方便規劃尚未涉及的書卷的系列。
- **會友**：會友和常來聚會者，按身份、年齡、性別和堂區分，以及期間加入或受洗的人。
- **場地**：期間內教會各場地的使用情況（聚會、聚會活動、活動、時數），所有 **重複預訂**（同一場地時間重疊；聚會按程序的分鐘數計算，聚會活動或沒有程序的聚會算一小時，沒有時間的活動算全天），以及不論所選期間、**未來 4 周** 的所有預訂。

## 圖書館 {#lending-library}

[圖書館](/lending) 用來管理教會借給會友的書籍、光碟和教材，與收錄詩歌、禮文和聖經的 **資料庫** 是分開的。這是 Canon 的可選功能：管理員在 **設置 → 功能模塊** 中開啟後，會出現在側欄的 **資源** 下。內置的 **圖書管理員** 角色可以使用這裡的所有功能，但看不到會友名冊；借閱者只按姓名選擇。

**目錄**
- **新增書籍**：輸入或掃描 **ISBN**（書背條碼上的號碼），再按 **查詢**。Canon 會從 Open Library（找不到時從 Google Books）填入書名、作者、出版社、年份和封面；只會送出 ISBN。沒有網絡或書籍沒有 ISBN 時，請自行輸入資料。選擇 **類別**（書、光碟、教材）、**分類**、**語言** 和 **書架**，並填寫 **副本** 數。
- 每冊都有編號（**B0001**、**B0002** ……）。**打印標籤**（在書籍中，打印所有副本）可把二維碼標籤印在 **A4 標籤貼紙**（每張 24、21 或 65 個；**從第幾個標籤開始** 可用部分用過的貼紙）或 **標籤打印機**（62 × 29 毫米）上。標籤上有二維碼、編號、書名和書架。請以 100% 比例打印。二維碼會以辦公室電腦的網絡地址在 Canon 中打開該冊書，手機須連上教會網絡。
- 副本可標記為 **遺失** 或 **已註銷**；從未借出的副本可以刪除。
- **導入 CSV** 可一次導入整份書單（每行一個書目，並註明冊數）；**導出 CSV** 可導出目錄。

**借出與歸還**：輸入副本編號（或用掃描器掃描二維碼標籤），再按 **查找**。
- **可借**：選擇 **借閱者**（輸入部分姓名；只限會友），確認 **歸還日期**（按 **借閱規則** 的借期），再按 **借出**。
- **借出中**：按 **收回**，或按 **續借** 再延長一個借期（不超過允許的續借次數）。
- 用手機相機掃描標籤也會打開同一張卡片。

**借出中** 列出所有借出的物品，逾期的排在前面（**逾期** 和 **已歸還** 分別列出）。會友若還有物品未歸還，在歸還之前不能刪除，也不能刪除其個人資料。

**借閱規則**：**借期**、**可續借次數** 和提醒時間。勾選 **每天以電郵發送提醒** 後，有電郵地址的借閱者會收到以其語言寫的電郵：在到期前所設定的天數收到一次「即將到期」，逾期後每週收到一次「已逾期」。使用教會的電郵帳戶（設置 → 電郵）。借出中分頁的 **立即發送** 可馬上發出今天的提醒。

**自助借閱**（借閱規則）：會友用自己的手機借書、續借和告知歸還，不需要 Canon 帳戶。
- **借書**：掃描書上的二維碼標籤，按 **借這本**，再用寄到會友名冊電郵地址的 6 位數驗證碼登入。驗證碼只能用一次，10 分鐘內有效；登入後在該手機上約兩小時有效。不在名冊中、或由多人共用的電郵地址不會收到驗證碼；頁面不會透露是哪一種情況。
- **續借**：在同一頁的 **我的借閱** 中續借，或按提醒電郵中的 **在線續借** 鏈接。打開鏈接不會改變任何內容；按頁面上的按鈕才會續借。
- **歸還**：按 **我要歸還**，借閱會標記為“已歸還：等候圖書管理員登記”，並顯示在 **借出中 → 待登記歸還**（首頁也會顯示），圖書管理員確認書已上架後按 **登記歸還**。期間不會再發提醒。
- **檢查項目**：只有所有檢查都通過時才能開啟自助借閱：**電郵正常**（自上次更改電郵設定以來，已在 設置 → 電郵 成功發送測試電郵）、**可連到這個 Canon 的公開 https 網址**（設置 → AI / MCP；Canon 會經由該網址呼叫自己來確認），以及 **圖書館已開啟並已保存借閱規則**。之後若有檢查失敗（電郵無法發送、網址無法連通），自助借閱會自動暫停：手機會提示找圖書管理員，檢查再次通過後會自動恢復。按 **再檢查一次** 可立即檢查。
- 開啟後請重新打印標籤：新標籤使用公開網址，離開教會 Wi-Fi 也能使用。安全與隱私檢查表會顯示自助借閱已開啟，以及本週寄出了多少個驗證碼。

## 資產登記 {#asset-register}

[資產登記](/equipment) 用來管理教會的設備與財產。這是 Canon 的可選功能（**設置 → 功能模塊**），位於側欄的 **資源** 下。內置的 **資產管理員** 角色負責管理。

- **新增物品**：**名稱**、**資產編號**（留空則使用下一個編號，**E0001** ……）、**類別**、**品牌型號**、**序號**、**存放地點**、**負責人**（會友，按姓名選擇）、**狀況** 和 **狀態**（使用中、存放、停用）。在 **購買** 下：**購買日期**、**價格**、**供應商** 和 **保修期至**。
- **照片與收據**：可加入照片（PNG、JPEG、WebP）和 PDF 收據或保修單，每個最大 10 MB。文件存在 Canon 的數據庫中，所以備份也會包括它們。
- **保養**：**每隔（月）** 和 **下次保養**。在 **保養記錄** 中按 **記錄**，寫下做了什麼、日期、由誰做和費用；設定了固定週期時，下次保養日期會順延相同的月數。列表中的 **需要保養** 顯示兩週內到期或已逾期的項目，首頁也會顯示數量。
- **打印標籤** 可為列表中的物品打印二維碼標籤，方式與書籍相同。二維碼會打開該物品：它是什麼、放在哪裡、由誰負責。
- **導入 CSV** 可導入現有的清單（每行一件物品）；**導出 CSV** 可導出資產登記。

## 設置

打開 [設置](/settings)。管理員會在左側看到分成四組的各個部分（**我的帳戶**、**教會**、**人員與權限**、**Canon**）；在手機上，從頂部的列表選擇。

- **我的資料**（所有人；管理員看到的是第一個部分）：顯示名稱、界面語言、**更改密碼**。
- **教會**、**語言**、**用戶帳戶**、**角色與權限**：見 [開始使用](#開始使用)。
- **場地**（管理員）：教會的禮堂、房間和其他地方——各語言的 **名稱**、**容量** 和 **備註**（例如投影機、鋼琴）。聚會、聚會活動和日曆活動都可選擇場地。⋯ 菜單可編輯、歸檔（已有的預訂保留，但不再供新預訂選用），或刪除從未被預訂的場地。
- **導出資料**（管理員）：一鍵下載 Canon 的各個部分——每個列表的 CSV（可用 Excel 打開，也可用 **導入 CSV** 再導入），含個人資料的會標明——以及 **下載全部（zip）**，內含所有 CSV 和資料庫文件。這不是備份：聚會、記錄和帳戶只在備份中。
  - **資料庫文件**：詩本、詩歌（含歌詞、詩本編號和 **樂譜**）、禮文，以及 **二維碼與短句**（勾選要包含的內容；**你上傳的聖經** 只在許可允許分享時才勾選），合成一個 `.canonlib` 文件。在另一個 Canon（其他教會或新電腦）按 **導入資料庫文件……**，會先顯示將加入的內容，然後只加入對方還沒有的：詩歌和禮文按代碼或標題配對，詩本按縮寫。已有的詩歌只會加入原本沒有的詩本編號和樂譜。上傳的聖經只在確認教會獲准使用時才會導入。
  - **資料庫各部分**：同樣格式的文件，一次一個部分——**詩歌** 按詩本逐本導出（含歌詞、編號和樂譜）、**不屬任何詩本的詩歌**、**禮文**、每個你上傳的 **聖經**、**二維碼與短句** 和 **投影背景**。管理員在資料庫每個分頁也有 **導出** 按鈕（詩歌分頁會列出各詩本），旁邊是 **導入資料庫文件……**。
- **功能模塊**（管理員；首次設定 Canon 時也會出現）：關閉教會不使用的部分——**聚會活動與日曆**、**同工與事奉表**、**新朋友表格**——或開啟需要的部分：**圖書館** 和 **資產登記** 默認是關閉的。關閉的部分對所有人隱藏（側邊欄、聚會程序的分頁、設置和報表），服務器也會拒絕，AI 助手也看不到。不會刪除任何資料：重新開啟即可恢復一切。
- **會友欄位**（管理員）：會友名冊中你自己的欄位——**文字**、**日期**、**是／否** 或 **從列表中選擇**（附選項），每個都有教會各語言的名稱，例如“小組組長？”、“如何加入”、“飲食需要”。勾選 **敏感** 可讓只讀帳戶和 AI 助手看不到（除非教會開放個人資料）。它們顯示在每位會友頁面的 **其他資料** 中，可篩選會友列表，也是會友 CSV 中的欄位（`custom_…`）。刪除欄位會把它隱藏；已填寫的資料會保留，再加入同一欄位時會重新出現。
- **奉獻**（管理員）：教會的貨幣、奉獻項目、**點算簽名方式**（紙本或屏幕）和 **最少點算人數**——參見 [聚會記錄](#service-records)。
- **電郵**：選擇 **電郵服務商**（Gmail、Microsoft 365 或其他），填寫 SMTP 資料並 **保存**，再按 **發送測試**。Gmail 須使用應用專用密碼。
- **安全與隱私**（管理員）：用簡單的話列出的 **安全檢查表**——磁盤加密（開啟 BitLocker 等之後按 **已完成**；Canon 無法自行偵測）、自動備份及其新舊、備份存放位置、備份加密、公開網址、管理員人數、兩步登入、每個帳戶是否屬於教會會友（或外部訪客）、六個月未使用的帳戶、AI 助手是否取得會友或新朋友的聯絡資料、新朋友表格、圖書館的自助借閱（開啟時），以及記錄保留多久——每項都說明該怎麼做。下方的 **誰查看了會友資料** 記錄每次有人打開會友頁面、AI 助手讀取會友資料或導出會友名冊（同一人同一頁面 10 分鐘內只算一次），可篩選、**導出 CSV**，保留期限與修改記錄相同。**保留與歸檔**：**新朋友聯絡資料保留多久後刪除**（默認 24 個月——刪除電話或電郵、代禱事項、自我描述和備註；姓名、如何來到和跟進會保留，報表仍可統計）和 **歸檔多少年以前的記錄**（默認 5 年，適用於聚會記錄及其奉獻），以及 **歸檔多少年以前的日誌**（除非另選年數，否則 **與記錄相同**，適用於修改記錄、AI 活動和查看記錄）。**查看可歸檔的資料** 會列出符合的整年；**立即歸檔** 會把這些年份的聚會記錄（連同奉獻）和日誌移到 `data/archives` 中，每年一個只讀文件——聚會本身仍會保留。已歸檔的年份可以 **打開**（聚會記錄和修改記錄，只讀）或 **下載**，每次備份也會一併複製歸檔文件。
  - **歸檔不會覆蓋記錄。** 如果還原的備份帶回一份也在歸檔中的記錄，只有兩者完全相同時才會繼續歸檔；否則會停止，並保留使用中的記錄不變。請取回歸檔中的那份，比較兩者。
  - **已歸檔的記錄是隻讀的。** 它的聚會在聚會記錄中顯示 **已歸檔**。任何人都不能為它新增記錄、刪除這次聚會或把它改到別的日期。要更正已歸檔的記錄，打開那一年並按 **取回**：記錄會回到聚會記錄中（會記錄在修改記錄裡），下次歸檔時會再次存入歸檔。
  - **刪除新朋友資料會處理 Canon 保留的每一份副本：** 聚會記錄、歸檔文件和修改記錄，包括之後被刪除的聚會的修改記錄。歸檔前會先刪除，所以過期的資料不會進入歸檔。備份中的副本會保留到該備份被刪除為止（設置 → 備份 → 保留最新的份數）；還原備份後會立即再次刪除。
  - **修改記錄的保留期限照樣適用：** 如果它比歸檔年限短，日誌會在夠舊可以歸檔之前就被刪除，這裡會提醒你。若希望歸檔也包括修改歷史，請把修改記錄保留久一點。
  - **報表只計算未歸檔的記錄：** 所選期間包括已歸檔年份時，報表頁會註明是哪幾年。
- **示例數據**（管理員）：**加入示例教會** 會在 Canon 中加入一間虛構的教會，方便試用——約 40 人分屬各家庭（丈夫、妻子和孩子），每人都有英文名和自己的中文名（不是翻譯）以及生日；按地區分的小組（東區、西區、北區和青年）、四個委員會、兩個團契和主日學；每個事奉團隊也有人。勾選 **也把他們排進事奉表……** 會填上下一堂聚會以及一週後其副本的空缺，讓次序單的 **下週服事** 和團隊分享頁有名字。每位示例人員的備註都會註明。**移除示例數據** 只會刪除當初加入的內容——這些人以及他們在小組、團隊和事奉表中的位置、他們的家庭和小組，以及複製的聚會——不會刪除任何人輸入的資料（已有真實會友加入的小組會保留）。
- **修改記錄**（管理員）：在 Canon 中、通過 AI 助手或 CSV 導入所做的每項修改——誰、何時、以什麼方式，以及每個欄位的舊值 → 新值。可按內容（會友、聚會、詩歌……）、人員、方式、新增／修改／刪除、日期或文字篩選，並翻閱較舊的記錄。**導出 CSV** 會下載符合篩選條件的所有記錄（最多 20,000 條），可用 Excel 打開。**保留** 設定保存幾個月（較舊的記錄每天刪除一次）。密碼絕不會被記錄。會友資料中的 **修改記錄** 按鈕顯示該會友的修改。
- **AI / MCP**：見下文。

## AI 助手

Canon 可以連接 Claude（claude.ai），你可以請它“按羅馬書 8 章策劃下主日的聚會”，或問“事奉表還缺哪些人？”。

### 連接 Claude

1. Claude 需要一個 **https** 公開網址才能連到 Canon，通常由負責電腦的同工設定隧道（tunnel）。
2. **設置 → AI / MCP**：開啟 **啟用 MCP 服務器**（立即生效；關閉時會先詢問，因為所有已連接的 AI 助手都會失去存取權），貼上 **公開網址**，按 **檢查**，再按 **保存**。
3. 在 **模塊權限** 為每個模塊選擇 **關閉**、**只讀** 或 **讀寫**，然後在有未保存更改時固定在窗口底部的欄中按 **保存 AI 權限**（各模塊的權限會一起保存，方便您先檢查）。**聚會記錄**（出席、新朋友姓名與跟進、備註）及其下的 **奉獻** 默認關閉，需要你開啟；奉獻永遠只能讀取——Claude 不會更改金額、簽名或確認點算，只讀帳戶也永遠看不到奉獻。
   兩個個人資料開關放在所屬模塊之下（模塊關閉時也一併關閉）：
   - **會友名冊 → 聯絡資料與生日**（**關閉** 或 **提供**）：會友的電話、電郵與住址、出生日期、備註和請假原因，以及同工和家庭的聯絡資料。默認關閉。
   - **資料庫 → 樂譜**（**關閉** 或 **提供**，默認關閉）：Claude 可列出聚會詩歌及其樂譜，並閱讀掃描頁面（例如“主日哪首詩歌最高音？”）。這些頁面會成為 AI 服務商處的副本：只有在教會可以複印該樂譜時才提供。PDF 不會傳送。Claude 無法自己上傳文件，但資料庫設為 **讀寫** 時，它可以給你一首詩歌的上傳鏈接（“為 HP 178 加入樂譜”）：用手機打開鏈接加入頁面。
   - **聚會記錄 → 新朋友**：**關閉**（只有出席人數；Claude 不能記錄新朋友）、**姓名與跟進**（姓名、如何來到和跟進情況；選擇“讀寫”時 Claude 可新增新朋友和更新跟進，但不含聯絡資料）或 **含聯絡資料**（另加電話或電郵和代禱事項——只有在已取得新朋友同意、可與 AI 服務商分享時才選擇）。0.15.1 之前已開放個人資料的教會從 **含聯絡資料** 開始，其他教會從 **姓名與跟進** 開始。
4. 在 claude.ai：**Settings → Connectors → Add custom connector**，貼上 **連接器網址**，client ID 留空，登入 Canon 並批准。

Claude 還會得到現成的工作步驟（策劃聚會、推薦詩歌、檢查事奉表、校對程序、編排要理問答進度、導入現有的次序單或投影片、為領袖撰寫每月報告……）。導入時，把現在用的次序單（PDF、Word 或照片）或 PowerPoint 交給 Claude：它會把詩歌和禮文與資料庫對照，建立聚會讓你檢查，並列出在模板編輯器中要選的設定。

Claude 會先參考你們過去的聚會：去年同一主日、同一節期、以前講同一卷書的主日、每首詩歌上次何時唱過、要理問答講到第幾問。它會按照教會慣常的程序、詩歌和事奉安排，避免重複最近幾週唱過的詩歌，並說明它的建議參考了哪幾堂聚會。

### Claude 看得到什麼

- 它只看得到你開放的模塊，並以批准連接的那個人的身份操作。只讀帳戶的連接永遠只能讀取。
- 除非會友名冊下的 **聯絡資料與生日** 設為 **提供**（且會友名冊已開啟），會友的聯繫方式和生日都不會顯示；新朋友的聯絡資料只在 **新朋友 → 含聯絡資料** 時提供。由只讀帳戶批准的連接，無論開關如何，都永遠拿不到聯絡資料——最多隻看到新朋友的姓名。
- 它不能發電郵或刪除人員。更改資料前它會先詢問。
- **管理**（默認關閉；只限由管理員批准的連接）：**只讀** 讓 Claude 讀取安全檢查表、備份、帳戶（絕不含密碼）、修改記錄、誰查看了會友資料和設置概覽——例如問“這週有什麼要處理的？”或“誰改了主日的程序？”。**讀寫** 另加兩個操作：立即備份，以及執行檢查（公開網址、備份文件夾、電郵）。帳戶、角色和設置只能在 Canon 中更改。只有在提供會友聯絡資料時，修改記錄才包含修改前後的內容。
- **已連接的 AI** 列出所有連接（按 **撤銷** 可中斷）；**使用記錄** 記下每個操作，最新的在前，可按模塊、用戶、客戶端、工具、成功或錯誤、日期及參數中的文字篩選，分頁顯示，可 **導出 CSV**（符合篩選條件的所有記錄），並有自己的 **保留** 期限。

## 備份與遷移到 Docker

- **備份**：[設置 → 備份](/settings?tab=backups)。按 **立即備份**，或開啟 **自動備份**（每天或每週；較舊的會自動刪除）。把 **備份文件夾** 設為 U 盤，或教會自己帳戶的同步文件夾（OneDrive、Google Drive），並按 **檢查**。備份是含個人資料的完整副本，請存放在只有辦公室能打開的地方。
- **加密**：在備份分頁設置 **備份密碼**（至少 10 個字符），按 **加密備份**。之後每份備份以及隨備份複製的歸檔文件都會加密（`.db.enc`），即使 U 盤遺失或雲端文件夾被分享，會友資料也不會外洩。這臺電腦會記住密鑰：自動備份不需要有人輸入，本機的備份還原時也不需要密碼。在另一臺電腦上，或還原更換密碼之前做的備份時，Canon 會要求輸入密碼。請把密碼和教會的記錄一起保存：沒有它，任何人都無法打開加密的備份。按 **停止加密** 後，新的備份會恢復為未加密的副本。若加密開啟期間這臺電腦的密鑰文件遺失或損壞，備份會停止並在分頁上提示——絕不會改為製作未加密的備份：請重新設置備份密碼，或按 **停止加密**。
- **儲存空間**（備份分頁頂部）：數據庫多大、哪些資料佔用空間（聖經經文、圖片、記錄、日誌……）、備份文件夾、磁盤剩餘空間，以及 Canon 增長多快（根據每天一次的讀數），空間不足前會提早警告。
- **還原**：按備份旁的 **還原**，或按 **從文件還原…** 使用這臺電腦上的備份文件（U 盤、另一臺 Canon）。Canon 會先保存目前資料的副本，所以可以還原那份副本來撤銷；備份之後所做的修改會丟失，你可能需要重新登入。如果 Canon 根本無法啟動，同一頁也列出手動還原的步驟。
- **更新 Canon**：先備份，關閉 Canon 窗口，用新版本的文件覆蓋舊文件（或 `git pull`），再啟動 `start-canon.bat`。它會安裝並重建有改動的部分。第一次啟動時會升級數據庫，並把升級前的數據庫副本保存在 `data/pre-upgrade/`（保留最新三份）。若新版本有問題，可用這份副本退回舊版本：見 `docs/UPGRADING.md`。舊版本的 Canon 不會打開已被新版本升級的數據庫，所以不會損壞它。各版本的改動：`CHANGELOG.md`。
- **遷移到 Docker**（服務器或 NAS）：先在辦公室電腦備份，在新機器用 `docker compose up -d` 啟動 Canon，再用 **從文件還原…** 還原備份（或按 `docs/DOCKER.md` 中 “Restoring a backup” 的步驟）。負責電腦的同工幾分鐘就能完成。

## 常見問題

**“Someone else changed this … after you opened it.”（有人在你打開後修改了這項資料）**
兩個人同時修改同一次聚會的資料、同一份聚會記錄或同一位會友。Canon 會保留先保存的修改，拒絕後來的保存，不會悄悄覆蓋，並說明是誰、在何時修改的。請先複製你輸入的內容，重新載入頁面看對方的修改，再重新輸入你的修改。

**導出的文件在 Excel 中中文變成亂碼。**
Canon 導出的文件可直接用 Excel 正確打開。若是你另存後出現亂碼，請重新另存為 **CSV UTF-8**。用中文編碼保存的文件，Canon 仍然可以讀取。

**投影的中文字體不對。**
投影只能使用投影電腦上已安裝的字體。可在 [投影模板](/slide-templates) 改用其他字體（如黑體或楷體），或在該電腦上安裝字體。

**小冊子的頁序不對。**
請雙面打印並選擇 **短邊翻頁**，然後把整疊紙對摺。建議先打印一份測試。

**更新後要求重新登入。**
若網址或端口改變、超過 14 天未登入、或密碼被重設，這是正常的。重新登入即可，資料不會遺失。若更新後畫面仍是舊的，請按 Ctrl+F5。

**Canon 打不開。**
在辦公室電腦上，“Canon server” 窗口必須保持打開。再雙擊 `start-canon.bat`（Mac 上是 `start-canon.command`）即可。如果 Canon 自己停止（出錯），窗口會在 10 秒後再次啟動（最多 10 次）；關閉窗口或按 Ctrl+C 則會完全停止。發生的情況會記錄在 `data/logs/canon-<日期>.log`（保留最近 30 天）——可把這個文件交給負責電腦的同工。

**某首詩歌沒有歌詞。**
它是從詩本目錄導入的。請在資料庫中打開它並輸入歌詞（須有授權）。

**Claude 看不到某些資料。**
請檢查 **設置 → AI / MCP → 模塊權限**，並按 **保存 AI 權限**。
