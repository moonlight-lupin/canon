# Canon 使用指南

Canon 帮助教会办公室策划主日聚会、打印次序单、投影，并管理各种名册。本指南按每周的工作次序编写。**粗体**字就是屏幕上显示的按钮或栏位名称。

> **提示：** 每个标题、诗歌、祷文都可以用教会的各种语言输入。简体与繁体中文在各处都会自动转换——画面、印刷品、电邮，以及新朋友表格等公开页面——中文只需输入一次。对话框或某部分有好几个这类栏位时，右上角的语言切换（**EN** / **简** ……）可一次把所有栏位切换到同一种语言，按 **左右对照** 则同时显示所有语言。每个栏位仍保留自己的语言小标签：点击只切换该栏位，把鼠标停在标签上则可看到该栏位在那种语言的全文，不必切换。

## 开始使用

### 第一次登入

1. 在浏览器打开 Canon（办公室电脑：`http://localhost:3000`；其他电脑使用 Canon 窗口（或时钟旁的 Canon 图标）显示的地址，即办公室电脑的网络地址，例如 `http://192.168.1.20:3000`）。若路由器给电脑换了地址，窗口会显示新的地址；负责电脑的同工可在路由器中为它保留固定地址。冒号后面的数字是端口：若要改用其他端口，可请负责电脑的同工在 `start-canon.bat` 旁边建立 `canon.local.bat`，写上一行例如 `set CANON_PORT=5018`。
2. 第一次会看到 **欢迎使用 Canon**。输入 **设置代码**：Canon 会在运行它的地方显示这个代码——在它的窗口或日志中（Docker 或 NAS：`docker compose logs canon`）——并在设置完成前保存在文件 `data/run/setup-code.txt` 中。只有看得到它的人才能创建第一个管理员，所以网络上的其他人无法抢先设置新的 Canon。接着选择 **聚会语言**（主要语言排第一），填写 **教会名称**、**显示名称**、**用户名** 和 **密码**（至少 8 个字符）。
3. 按 **创建管理员**。界面语言可在顶部切换为 **EN**、**简体中文** 或 **繁體中文**。

### 语言与圣经

接着出现 **开始设置**：**模块**（教会使用的 Canon 功能）、**Canon 自带资料库**、**恢复密钥**，以及与 [设置 → 语言](/settings) 相同的画面。

**恢复密钥。** Canon 从第一次启动起，就在运行它的电脑上加密教会的资料：没有 Canon 的密钥，就无法读取数据库、其副本和备份。密钥会通过运行 Canon 的 Windows 帐户（Mac 上是钥匙串）自动打开，所以电脑启动时 Canon 仍会自行启动，不需要有人在场。若那台电脑或该帐户遗失，**恢复密钥** 就是重新打开资料的方法，也能在任何电脑上还原教会的备份。按 **制作恢复密钥**：Canon 只会显示它 **一次**，共八组，每组五个字母或数字，并附二维码。请 **打印**（或抄下），把纸张存放在电脑以外的地方——和教会的重要文件放在一起或放进保险箱——勾选已妥善保存，并输入它的最后五个字符。完成之前，**完成设置** 会一直等待。

**Canon 自带资料库** 是可选的：勾选要加入的内容，再按 **加入资料库**。不按就不会加入任何内容；其余的之后可在 [资料库](/library) → **Canon 自带资料库** 加入。

- **诗歌与诗篇**：约 380 首公共领域的诗歌、韵文诗篇与礼仪短歌，含英文歌词与作者资料。
- **礼文**：信经、宣召、认罪文、祷文与祝福，中英文。
- **聚会模板**：五个使用这些诗歌与礼文的聚会次序。
- **威斯敏斯德信仰准则**：小要理问答、大要理问答与信仰告白（英文），从互联网下载。

然后：

1. **聚会语言**：勾选教会使用的语言；第一个是主要语言。有 **UI** 标签的语言，表示 Canon 本身的画面也已译成该语言（并显示翻译了多少，例如“UI 82%”），同工可用该语言使用 Canon；其他语言只用于聚会。任何人都可以不写程序就新增或改进一种语言：请参阅 Canon 文件中的 `CONTRIBUTING-TRANSLATIONS.md`。
2. **圣经**：为每种语言按 **下载并导入**，取得公共领域的圣经（KJV、和合本等），并选择 **默认译本**。
3. **次序单与投影**：选择 **默认印刷与投影的语言**（最多 3 种）和 **双语排版**（**左右对照** 或 **上下排列**）。
4. 按 **完成设置**。

> **提示：** 有授权的译本（ESV、和合本修订版、新译本等）之后可用 **＋ 添加圣经译本** 上传，详见 [圣经](#圣经)。

### 教会资料与标志

打开 [设置](/settings) → **教会**：教会名称、**教会标志**（**上传标志**：PNG、JPEG 或 WebP，最大 2 MB；0.19.11 之前上传的 SVG 标志仍会显示，但 Canon 已不再接受 SVG（可能夹带脚本），请换成 PNG）、地址、**联系信息**（印在次序单上）、**CCLI 授权编号**、**默认开始时间** 和 **时区**——决定 Canon 里的“今天”：报销与日记账的日期、截至今天的报表、未来的事奉表和聚会、新朋友表格何时开放（默认为运行 Canon 的电脑的时区；Docker 中是 `TZ` 设定）。按 **保存**。

### 一间教会，几个堂 {#congregations}

如果一间教会有几个堂（例如英文堂、华文堂、印尼堂），可在 **设置 → 教会 → 各堂** 按 **新增堂** 加入：名称、标记用的 **简称**（EN、华、ID）、颜色，以及 **聚会所用语言**。之后：

- 聚会、聚会模板、会友和小组都可以在表单的 **所属堂** 栏位标记所属的堂；
- **聚会**、**会友**、**小组** 和事奉表会出现 **全部 · EN · 华 · ID** 筛选按钮，并在这台电脑上记住选择；
- 某个堂的新聚会会预先选用该堂的语言；聚会模板也可以归入某个堂，用它建立的聚会也归入该堂。

只有一个堂的教会把列表留空即可，不会看到这些功能。删除一个堂时，它的聚会、会友和小组都会保留，只是不再标记所属堂。

### 添加同工帐户

**设置 → 用户帐户 → 添加用户**。每个帐户都属于一位教会会友：在 **会友** 中选择（若名单中还没有，请先在 [会友](/members) 中加入）。只有 **外部访客** 帐户不需要会友。你输入的密码只用于第一次登入：对方须先设定自己的密码，Canon 才会打开（在对方设定之前，列表显示 **须设新密码**）。为别人 **重设密码** 时也一样。设置 Canon 的管理员可以先不连结；在连结自己的帐户之前，每页上方都会有提醒（**连结我的帐户**，或按 **稍后提醒** 至下次登入）。

选择角色：
- **管理员**：所有功能，包括设置、帐户和角色。
- **牧者 / 长老**：会友及其资料和备注、群组、聚会活动和主日聚会；可查看记录和奉献。
- **编辑**：策划聚会，编辑名册、资料库、事奉表和记录（与 0.13 之前相同）。
- **聚会策划**：主日聚会、模板、资料库和事奉表；会友只看姓名。
- **财务**：聚会记录和奉献——输入、核实和重开现金点算——以及 [财务账簿](#bookkeeping) 和 [报销申请](#claims)（开启后）；其余只能查看。任何人都可以申请报销；报销由指定的人审批，不是由角色审批。
- **文书**：名册——会友、同工、群组、聚会活动和聚会记录及其新朋友（不包括奉献）。
- **只读**：可查看和打印；不看奉献、会友联络资料或备注。
- **图书管理员** 和 **资产管理员**：只管理 [图书馆](#lending-library) 或 [资产登记](#asset-register)（教会开启该功能时）。
- **外部访客（只读）**：供教会以外的人使用，例如审计员。可查看主日聚会、资料库、聚会记录和奉献，不能更改任何内容，也绝不看会友联络资料或备注；不连结到会友。可以让它查看更多（角色 → **编辑**），但不能让它更改。

若帐户的角色不是 Canon 认得的角色（例如从别处复制资料进来之后），在管理员为它选择角色之前，这个帐户 **没有任何权限**：本人会看到原因，设置 → 用户帐户 也会标示这个帐户。

**设置 → 角色与权限**（管理员）显示每个角色在 Canon 各部分的权限：**无权限**、**查看** 或 **编辑**，以及是否可查看会友的联络资料和备注、标为敏感的栏位，以及可否重开已核实的现金点算。把指针停在角色的 **?** 上可读到它的用途。名称旁的 **编辑** 用来调整角色（预设角色也可调整以配合教会；管理员始终拥有所有权限）。它的 **⋯** 菜单有 **复制**（以此角色的副本开始一个新角色，例如“秘书（不含财务）”）、**归档**（没有帐户使用的角色：保留，但新增帐户或更改帐户角色时不再提供；已归档的角色放在 **已归档的角色** 下，按 **还原** 可恢复），以及教会自己没有帐户使用的角色可 **删除**。**新增角色** 可从头加入，例如可编辑聚会和资料库的敬拜主领。Canon 的预设角色可以归档，但不能删除。角色无法查看的页面不会出现在侧边栏；代表某人工作的 AI 助手也遵循同一个角色。看不到敏感栏位的角色也不能修改它们：会友表格上不会出现这些栏位，保存会友时它们保持不变。

**安全登入**：
- 连续输入 5 次错误密码——或错误的两步登入验证码——帐户须等 1 分钟才能再试；之后每次再输错，等待时间就更长（2、4、8 分钟，最多 15 分钟），等待期间的尝试不计算在内（列表显示 **已锁定**；按 **重设密码** 即可结束等待）。**你以前登入过的浏览器不受影响**：即使别人猜你的密码而令帐户须等待，你自己的电脑和手机仍可用正确密码登入。设定新密码后，这些浏览器就不再被记得。登入页面对密码错误和帐户等待的回应相同，所以无法用它查出哪些用户名存在。同一个地址在 15 分钟内输错 8 次密码或验证码（不论哪个帐户），该地址就要等待；登入成功只会抵消在自己帐户上的错误尝试（打错后再输入正确密码）。
- **管理员设定的密码**（新帐户，或 **重设密码**）只能用一次：Canon 会请你设定自己的密码，之后才会打开。在你设定之前，也不能为这个帐户连接 AI 助手。
- **更改密码，或开启或关闭两步登入，会让你在其他地方都被登出**（其他电脑、你的手机）；你进行更改的地方仍保持登入。管理员为某人重设密码或两步登入时，对方会在所有地方被登出，连接的 AI 助手也会断开（请在 AI 助手中重新连接）。更改自己的密码不会断开你自己连接的 AI 助手。
- **两步登入**（设置 → 我的资料 → **设定两步登入**）：用手机上的身份验证应用（Google 或 Microsoft Authenticator、1Password 等）扫描二维码，输入应用显示的验证码 **和你的密码**，再按 **开启**。之后每次输入密码后，Canon 会要求输入 6 位数验证码。每个验证码只能用一次：如果 Canon 不接受你刚用过的验证码（例如刚用来开启两步登入的），请等下一个验证码。请保存只显示一次的 8 个 **恢复码**（四组，每组四个字母或数字；输入时可加或不加横线）：手机遗失时，每个恢复码可登入一次。**新的恢复码**（需输入密码）会取代全部旧的恢复码——在快用完时，或“我的资料”提示你的恢复码是较旧、较短的一种时使用（0.19.9 之前产生的恢复码在用掉之前仍然有效）。
- **你会收到通知**：有人用恢复码登入你的帐户，或管理员重设你的两步登入时，每页上方都会显示通知（包括时间和来自哪个地址），直到你按 **知道了**；若教会已设定电邮（设置 → 电邮），也会发电邮到你会友资料上的地址。开启或关闭两步登入、产生新的恢复码时也会发电邮。如果这不是你本人，请立即更改密码并告知管理员。
- **重设两步登入**（管理员，在用户列表中）可为遗失手机的人关闭两步登入（对方会收到通知，如上所述）。在安全与隐私中按 **要求管理员使用** 或 **要求所有人使用**，这些帐户都必须使用两步登入：未设定的帐户登入后只会看到设定画面，设定完成后才打开 Canon。连接到这类帐户的 AI 助手也会停止运作，直到设定完成。要把两步登入转到新手机，请先关闭（需输入密码），再重新设定。

**限定于**（有几个堂的教会）：限定于某个堂的帐户，只看到该堂以及全教会的聚会、聚会活动、记录、会友、群组和活动——看不到其他堂的资料；它新建的项目属于该堂，报表也只关于该堂。代表它工作的 AI 助手同样如此；经由其他项目看到的人（群组成员、轮值表、家庭）也一样：其他堂的人不会显示，也不能加入它的群组或轮值表。要把项目移到另一个堂，需要全教会的帐户。成员全属其他堂的家庭也不会显示给它。在图书馆和资产登记中，借阅和物品仍会显示，但其他堂的借阅人或负责人只显示为 **另一个会众**，不显示姓名。在 **财务账簿 → 报销** 中，它看到该堂以及全教会的报销（报销属于申请人所在的堂），也只能为这些会友输入报销；账目、报表和批准人仍属全教会，因为账簿只有一套。管理员始终可以看到全部。
- **聚会带领者**：把帐户连结到所属的会友（**会友** 一栏）。在群组中被勾选为 **带领** 的会友，或被选为某次聚会 **带领者** 的会友，就可以用那个帐户（即使是只读帐户）记录那些聚会活动：人数、新朋友及其联络资料（以便跟进）、备注、奉献及其现金点算和签名、聚会的详情和下一次聚会。其他方面不变：主日聚会、其他聚会活动和名册仍是只读的；删除聚会活动或重开已核实的点算，仍由编辑和管理员负责。

| 功能 | 管理员 | 编辑 | 只读 |
|---|---|---|---|
| 查看聚会、资料库、名册、小组、事奉表 | ✓ | ✓ | ✓ |

AI 助手总是以连接它的人的身份工作，权限不会超过那个人的角色（见 [AI 助手](#ai-助手)）。

## 每周工作

侧边栏把页面分组：**策划**（主日聚会、聚会活动、资料库和三种模板）、**会众**（小组与团契、会友、同工、事奉）、**记录** 和 **管理**。点击部分的名称可收起，再点一次即可展开；Canon 会在你的浏览器中记住这个设定；前往已收起部分中的页面时，该部分会重新展开。

[概览](/) 是首页：下一堂聚会及其状态、未来几周尚未安排的岗位与冲突（把指针停在 ⚠ 或「岗位待排」标签上，或在手机上轻点，就能看到详情）、近期生日，以及次序单和投影的快捷入口。问候语会随一天的时间和教会年历（将临期、圣诞期、复活期……）改变，主日和重要节期另有问候，偶尔还有惊喜——平安（Shalom）、唯独荣耀归于神、哈利路亚（大斋期不用）。底部是资料库：诗歌和礼文的数目，以及每种语言已安装的圣经译本；点击卡片会打开资料库的相应部分。每个部分只显示你的角色可以打开的内容：例如图书管理员会先看到图书馆，不会看到会友、聚会或诗歌。若某个角色目前什么都不能打开，首页会说明。

[日历](/calendar) 把主日聚会、聚会活动和教会其他活动放在一起：**月**、**周** 或 **列表**（接下来八周；手机上显示为列表），可按堂（连同全教会的项目）和群组筛选。点击主日聚会或聚会活动即可打开。**新增活动**（编辑）可加入教会日历上的其他事项——营会、婚礼、清洁日等——填写日期（持续几天的活动填 **结束日期**）、时间、**场地**（教会的场地，已被预订时会提醒）或地点、堂和群组；点击活动可更改或删除。

**一周概览：**

```flow
[策划] 策划聚会：从模板 **＋ 新建聚会**——诗歌、读经、讲道
[策划] 轮值和提醒：谁服事，并在主日前发电邮给他们
打印程序单 | 投影幻灯片 | 把流程表分享给同工
[主日] 举行聚会
[办公室] 聚会记录：出席人数、新朋友、奉献点算
[点算员] 现金点算签名并核实——账簿里会起草它的分录
```

### 1. 策划主日聚会

1. 进入 [聚会](/services)，按 **＋ 新建聚会**。
2. 确认 **日期**（默认为下一个主日），填写 **经文**（例如 以赛亚书 6:1-8）和 **讲题**。**讲员** 来自事奉表（讲道项目的带领人）。
3. 选择 **模板**（或 **空白程序**），再按 **新建聚会**，便会打开聚会程序。
4. 在聚会资料中选择举行的 **场地**（管理员先在 设置 → 场地 加入教会的场地）。若同一场地在同一时间已被其他聚会、聚会活动或活动预订，会显示提醒并列出它们；仍可保存，因为有时是刻意共用礼堂。

**聚会程序**

- 把鼠标移到两个项目之间，按小小的 **＋**（**在此插入**），选择类别（**诗歌**、**读经**、**礼文**、**祷告**……），然后搜索，或选 **先加入空位，稍后填写**。
- 也可以用右边的资料库面板（**诗歌与诗篇**、**信经与礼文**、**经文**、**图片**、**程序元素**）：点击即可加入，或把它拖进程序中。从 **图片** 加入的图片会成为一个只在投影中出现的独立项目（不印在次序单上）——例如报告事项之后的海报。
- 每首诗歌都会显示在本堂聚会之前 **上次** 何时唱过（或 **未唱过**）；如果在之前四周内唱过，会以醒目颜色标出，提醒你避免重复。
- 调整次序：拖动项目左边的把手，或打开项目后按 **上移** / **下移**。
- 出现 **诗歌 ?** 或 **经文出处 ?** 标记，表示该空位还要填写。

**编辑项目**：点击项目即可，改动会自动保存。

- **诗歌**：选择诗歌，勾选要唱的 **节数**（副歌会自动印出）。若一首诗歌收在几本诗本中，可在 **诗本** 选择显示哪一本的编号。
- **读经**：输入 **经文出处**（`罗马书 8:28-39`、`诗 23`、`约 3:16`）。每种语言可为这段经文另选 **圣经译本**。
- **礼文**：选择礼文。要理问答在 **问答** 输入题号，例如 `1-3` 或 `Q4-6`；按 **下一组** 可跳到接下来的问答。
- **姿势**：众立或众坐会印在次序单上。
- **印在次序单**：**依模板**、**完整内容**、**只印标题** 或 **不印出**。**显示于投影** 决定是否投影该项目。
- **投影**（在 **显示在投影** 旁边）：**只显示内容**（照常显示文字）、**只显示封面**——一张有项目名称和负责人的投影，例如只显示“三叠阿们”而不是三次阿们——或 **先封面，后内容**，例如在经文前先显示“读经 · 李路得”。PowerPoint 和 FreeShow 文件也一样。
- **带领** 只能选这堂聚会事奉表上的人——不能自行输入名字。有 **岗位** 时，事奉表上该岗位的人全部勾选；取消勾选部分人，就只印所勾选的（例如两位招待中的一位）。没有岗位时，可从这堂聚会事奉表上的任何人中勾选（默认无人）。请先在 **事奉团队** 中排人。0.15.10 之前输入的名字，在未从事奉表选人前仍会印出；策划页会显示为 **之前输入**，并有 **移除** 按钮。复制的聚会不会带上输入的名字。聚会的 **讲员** 就是 **讲道** 项目的带领人（在该项目中选择），不能自行输入。
- **投影片上的二维码与短句** 可在该项目的投影片上加二维码或短句。
- **投影图片** 显示 **资料库 → 图片** 中的图片，每张在该项目的投影片之后独占一张投影片（不在投影中的项目只显示其图片）。可加入多张，用 ‹ › 调整次序，按 × 移除。PowerPoint 和 FreeShow 下载也会包含这些图片，但不会印出。
- **投影背景** 只在这个项目的投影片后面放一张图片（例如圣餐的饼与杯），取代投影模板的背景。图片从 **资料库 → 投影背景** 中选择（可输入文字搜索）。图片会用模板的背景色淡化，让文字清楚易读；PowerPoint 下载也会使用。

**聚会资料**：按程序上方的 **编辑…**，可更改日期、时间、语言（最多 3 种）、**圣经译本**、**教会节期**、**次序单封面**、**次序单模板**、**投影主题** 和 **参考代码**（你为这次聚会定的简短代码，例如 `EN-2026-12-25`）。改好后按该卡片中的 **保存**。

**参考代码。** 聚会和三种模板都可以有 **参考代码**：你自己定的简短代码（字母、数字和 - _ .，不可有空格，例如 `EN-001` 或 `CN-10pmService`），同一类中不可重复。它会显示为小标签，可代替名称使用——同工和 AI 助手都可以，例如“用模板 CN-10pmService 建立下主日的聚会”。在聚会资料、聚会模板编辑器中设定，投影或次序单模板则在 **⋯** 菜单按 **设定参考代码…**。

程序准备好后，把顶部的 **草稿** 切换为 **定稿**。

> **提示：** 在 **输出** 栏末端的 **⋯** 菜单中，**复制** 可把整个程序复制到另一个日期（可连同事奉名单），**另存为模板** 可把满意的程序存成模板；**删除这次聚会** 也在那里。

### 2. 事奉安排与提醒

打开 **事奉团队** 分页。

1. 在每个岗位下按 **＋ 添加** 选人（**可事奉岗位** 列出平常事奉这个岗位的人；外出的人会有标记）。
2. 点击名字可切换状态：**已安排 → 已确认 → 已婉拒**。按 **×** 移除。
3. 查看 **提醒** 栏：未排满的岗位、重复安排、外出的人。
4. 按 **发送提醒**：勾选 **收件人**，需要时加上 **附注**，查看 **预览**，再按 **发送给 N** → **立即发送**。

> **提示：** 系统绝不会自动发送电邮，电邮发出后也无法收回。若想在电邮中附上聚会程序，请先启用分享链接。须先在 设置 → **电邮** 完成设定。

### 3. 打印次序单

**本周家讯**：打开程序策划页的 **次序单** 分页（在 **聚会程序** 和 **事奉团队** 旁边）。这里列出该聚会所用次序单模板的每周内容：先是 **报告事项**（家讯），然后是 **牧者的话** 等每周内容。每种语言分别输入，会自动保存。**有编号的行会印成列表。** 程序中的 **报告** 项目仍保留为有时间的项目，但它的内容现在印在报告事项部分。以前把家讯写在该项目里的聚会，会预先填好内容并显示 **请保存以保留**。若分页显示 **这个模板没有每周内容**，请在模板的页面编排中加入 **报告事项** 或 **每周内容**。

1. 在程序的 **输出** 栏按 **次序单**。
2. 选择 **模板**、**纸张**（通常是 **A4 横向对折（A5 小册）**）、语言、排版和 **字号**。
3. 按 **打印**。

> **提示：** 小册子要 **双面打印，短边翻页，然后对折。** 对折小册子的页数必须是 4 的倍数：若显示「共 5 页——将加入 3 个空白页，以便对折成小册子（共 8 页）」，空白页会加在封底前面。若提示内容超出一页，请缩小字号，或把较长的项目改为只印标题。

### 4. 投影

1. 在 **输出** 栏按 **投影片**，会在新分页打开；把该分页拖到投影屏幕，按 **F** 全屏。
2. 按 **打开主控窗口** 在自己的屏幕上显示当前与下一张投影片、备注和时钟。两个窗口必须在同一台电脑的同一个浏览器里。

| 按键 | 作用 |
|---|---|
| → / 空格 / Enter | 下一张 |
| ← / Backspace | 上一张 |
| **B** | 黑屏 / 恢复 |
| **W** | 清除文字（只留背景） |
| **F** | 全屏 |
| **O** | 总览所有投影片 |
| 数字 + Enter | 跳到该张 |

**输出** 栏的 **文件** → **PowerPoint 幻灯片** 会把投影片下载为 PowerPoint 文件，方便在没有 Canon 的电脑上使用，或发给音控同工。文件沿用该聚会的幻灯片模板（颜色、背景图片、字体、字号、每张行数、页脚和屏幕比例）；**自定义 CSS** 不会带过去。用 PowerPoint 打开后按 **F5** 放映。各语言的文字使用模板字体中 Windows 电脑有的第一个（否则用 Georgia、宋体 SimSun 或微软正黑体）。

在 Mac 上请选择 **文件** → **PowerPoint 幻灯片（Mac 的 Keynote）**：同样的投影片，使用每台 Mac 都有的字体（宋体 Songti、苹方 PingFang、Helvetica Neue 等）。用 Keynote 打开（**文件 → 打开**）后按 **播放**；**文件 → 存储为** 可存成 Keynote 文件。

**核准**（在 **输出** 栏；可编辑该聚会的人都可使用）：保存次序单和投影目前的副本——文字、次序、人员、次序单模板和幻灯片模板——连同日期、核准人和可选的备注。之后按钮会显示 **已核准**，聚会更改后则显示 **核准后已更改**。**已核准的版本** 列出所有版本；按其旁边的 **次序单** 或 **投影片**，即可按核准时的原样打开那个版本（顶部有绿色提示），即使聚会之后已更改。图片只是引用，不会复制。

### 5. 与事奉团队分享

- **流程表**：可打印的时间流程，列出带领者和影音提示。**投影片** 栏列出每项的投影片编号，影音提示注明每部分从第几张开始——例如每节后都唱副歌的诗歌：“1 → 3 · 2 → 6 · 3 → 9 · 副歌 → 5, 8, 11”，以及二维码或短句投影。编号与投影片页脚的编号相同，操作员可输入编号再按 Enter 跳过去。编号以标题投影为第 1 张，按聚会目前的内容计算：内容更改后请重新打印。
- **乐谱**：按次序列出聚会的诗歌、要唱的节数，以及资料库中每首诗歌的乐谱（见 [资料库](#资料库)）——可打印，或在钢琴旁用平板打开。没有乐谱的诗歌也会列出，乐手便知道要自备；PDF 会另行打开。
- **分享**（在 **输出** 栏；有链接生效时显示 **开启**）有两个链接：
  - **分享给团队**：按 **启用链接**，再按 **复制** 把链接发给大家。链接只读，不含联系方式。除了聚会程序，还列出只有团队需要的内容：聚会的 **备注**（在最上方，标题为 **给事奉团队的备注**）、各项目的备注（在该项目下方）、今日事奉同工，以及下一堂聚会的服事人员。**停用链接** 后旧链接失效；重新启用会产生新链接。
  - **给会众的次序单**：每堂聚会一个链接，让会众在手机上看次序单——聚会程序、诗歌和经文、报告事项，可切换语言；不含事奉同工、团队备注或联系方式。可勾选 **在次序单封底印出二维码** 和／或 **在标题投影角落显示二维码（会众进场时）**——聚会开始前显示的那一张，适用于 Canon 投影和 PowerPoint 文件（FreeShow 项目则作为第一个节目），或按 **下载二维码** 用在别处。**停用链接** 后链接失效。
  - 两个链接（以及新朋友表格、寄给团队的电邮和二维码标签）都使用教会的 **公开网址**（设置 → AI / MCP）。没有公开网址时，会使用这台电脑在教会网络上的地址，绝不用“localhost”或电脑名称，因此只能在教会自己的网络中打开。
- **文件** → **PowerPoint 幻灯片**、**Word 文件** 和 **FreeShow 项目** 可下载给其他软件使用。
- **在手机或较窄的窗口上**，次序单、流程表、乐谱、新朋友卡、现金点算声明和标签会缩小显示，让整页符合屏幕宽度；打印时仍是实际大小。
- 连接 Canon 的 AI 助手也可以为这些文件生成 **下载链接**（约一天后失效）。持有链接的人无需登录即可下载该文件，请只发给需要的人。
- **电邮事奉团队** 会用你自己的电邮软件打开新邮件，团队成员放在密件副本。

## 聚会活动 {#meetings}

[聚会活动](/meetings)（侧边栏 **策划** 之下）包括团契聚会、小组、祷告会、主日学班、委员会会议和单次聚会——比主日聚会简单，有自己的记录。

### 策划聚会活动

- **新建聚会活动**：选择群组和日期。群组的新聚会会复制上一次的聚会（时间、地点、带领者、是否收奉献）；第一次会用群组的名称。单次聚会请选择 **不属于群组**，并填写标题。
- 聚会页面上有：**标题**、**日期**、**开始时间**、**场地**（教会的场地；下一次聚会会沿用，重复预订会显示提醒）或 **地点**（其他地方，例如家中）、**带领者**（会友；不在名册中的人可改为输入姓名）、**经文**、**主题** 和备注。**下一次聚会** 会把这次聚会复制到另一个日期（默认一周后）。

### 奉献与新朋友表格

- **这次聚会收奉献**：每次聚会各自开关（下一次会沿用）。收奉献时，记录中有现金点算、点算声明和签名，与主日聚会相同；不收奉献时，只有人数、新朋友和备注，这次聚会也不计入奉献报表。
- **新朋友可用手机填写表格**：与主日聚会相同的新朋友表格（须先在 设置 → 新朋友表格 开启）。勾选后，这次聚会活动会有自己的二维码和链接，并可 **打印卡片**；填写的资料会在下方等你 **接受** 后加入这次聚会活动的记录。聚会活动的带领者也可以这样做。

### 记录聚会活动

**记录这次聚会** 会打开它的记录。聚会程序、次序单和投影都是可选的（**新增聚会程序**）。

群组的带领者可以用自己的帐户（即使是只读帐户）记录群组的聚会活动：管理员把帐户连结到所属的会友（设置 → 用户帐户），群组再勾选谁是 **带领**（见 [会众](#people)）。聚会活动本身的 **带领者** 也可以记录。

### 定期聚会

**聚会规律**（在 **编辑群组** 中）：**每周**、**每两周** 或 **每月一次**（第一个……第四个或最后一个星期几），以及 **开始时间** 和 **地点**。**预先建立聚会** 会每天建立那么多周之内的聚会（0 = 只在你按群组中的 **预先建立聚会** 时建立），每次都复制上一次，带领者只需打开当晚的聚会。个别聚会仍可单独更改日期或删除，而且会保持这样：群组页面会在 **已取消或改期，因此不会按固定时间建立** 之下列出这些日期，按 **还原** 即可恢复（会在下次建立未来聚会时建立）。

## 资料库

打开 [资料库](/library)。

### 诗歌与诗本

- **诗歌**：可按标题、歌词或编号（`HP 123`）搜索。**新建诗歌**：标题、作者、曲调、诗节（副歌的标签写 `R`）、**诗本编号**。取消勾选 **公共领域** 即可填写版权和 **CCLI 诗歌编号**。
  - **每节后都唱的副歌**：只输入一次，作为标签为 `R`（或合唱用 `C`）的诗节，并勾选 **每节后唱副歌**。在聚会中只勾选要唱的数字诗节，Canon 会在每节后加上副歌。投影片每次都完整显示副歌；次序单第一次完整印出，之后各节后只印“（副歌）”。投影上，每一节（或副歌）的每一张投影上角都会显示节数（或“副歌”），不只是第一张。
  - **乐谱**：按 **新增页面** 加入乐谱的扫描或照片（PNG、JPEG 或 WebP）或 PDF，每个最大 10 MB；用箭头调整页序。有乐谱的诗歌在列表中显示 ♫ 和页数。乐手可在聚会策划的 **输出 → 乐谱** 找到。乐谱只留在 Canon 内（及其备份中）：不会出现在分享页或投影片；只有在管理员提供时（设置 → AI / MCP），AI 助手才能阅读。只保存教会可以复印的乐谱（公共领域，或在教会的版权许可之内）。
    - **用手机**：显示一个二维码。用手机扫描后逐页拍下诗本（或选择文件），就会成为这首诗歌的下一页，无需登入。链接有效 24 小时。
    - **上传乐谱**（列表上方）：一次上传多个扫描文件。请以诗本编号为文件命名，例如 `HP 178.jpg`，第二页为 `HP 178-2.jpg`（只写 `178.jpg` 时使用第一本有这个编号的诗本）。Canon 会把文件配对到诗歌；请检查列表，可更改或略过，选择是否 **取代** 原有页面，然后上传。
- **Canon 自带资料库**（管理员，在 诗歌 与 礼文 分页）可加入 Canon 自带的公共领域诗歌与诗篇、礼文、聚会模板和威斯敏斯德信仰准则，与设置 Canon 时的选择相同。每一部分都会显示资料库中已有多少。诗歌含英文歌词、作者、曲调与格律；少数注明其常用曲调或和声仍有版权，但歌词本身可自由印刷与投影。您可以在诗节中加上中文歌词，或删除不用的项目：删除的项目在 Canon 更新后不会再出现。勾选 **也加回删除过的项目** 即可加回。
- **诗本**：**新增诗本** 并填写 **缩写**（显示在编号前，如 HP 123）。排第一的诗本是默认编号。
- 要导入诗本目录（编号与标题），在该诗本使用 **导入…**。资料库中没有的诗歌会以“只有标题”的方式加入，并加上 needs-words 标签；歌词绝不会被导入。

> **提示：** 有版权的歌词，只能在教会持有授权的情况下输入。

### 礼文与要理问答

- **新建礼文**：选择类别（宣召、认罪、信经、要理问答……）。启应文每行以 `L:`（领）、`C:`（会众）或 `A:`（齐）开头；空一行表示新段落或新投影片。
- **分为编号部分** 可把长篇礼文分成编号部分（例如问答）。要理问答第一行是 `L: 问题`，第二行是 `C: 答案`。
- **导入威斯敏斯德信仰准则**（管理员）会加入小要理问答、大要理问答和信条（英文）。

### 圣经

- 资料库 → **圣经**：输入 **经文出处** 或 **搜索** 字词；**＋ 对照** 最多可并排 4 个译本。
- 添加有授权的译本：**设置 → 语言 → ＋ 添加圣经译本**。下载 CSV 模板（`book, chapter, verse, text`），在 Excel 另存为 **CSV UTF-8**，勾选授权确认，检查预览后导入。
  - **许可与可用范围**（管理员）：已安装译本旁的锁形按钮可记录其 **版本**、**许可** 文字以及可用于哪些用途——**印刷**（周报、Word 文件）、**投影**（幻灯片、演示文件、FreeShow）和 **网上**（公开分享页面）。新上传的译本可以印刷和投影，但在勾选 **网上** 之前不会放到网上；公版译本全部允许。不允许的用途，该输出只显示经文出处而不显示经文，聚会编排页面会在程序上方提醒（**圣经许可**），以便改选其他译本或贴上获许可的经文。重新上传同一译本会保留已记录的设定。
  - **印尼文**：Canon 没有附带印尼文圣经。常用的译本（Terjemahan Baru，以及较早的 Terjemahan Lama）由印尼圣经公会（Lembaga Alkitab Indonesia）持有权利，教会须取得圣经公会许可后自行上传所用的译本。

### 图片

**资料库 → 图片** 保存投影用的图片：报告事项的海报、短宣的照片、地图等。按 **加入图片……** 可上传一个或多个 PNG、JPEG 或 WebP 文件（每个最大 10 MB），图片按文件名命名。每张图片独占一张投影片（在聚会策划中选择：项目 → **投影图片**，或程序单旁的 **图片** 分页），可选 **完整图片**（显示在投影模板的背景上）或 **铺满投影片**（裁去边缘以填满）。每张卡片会显示尺寸（在宽屏投影机 1920 × 1080 上需要放大时会提醒），以及有几个项目使用。可 **改名**、**替换**（所有显示它的项目都会换成新图片）或删除；删除的图片会从显示它的投影中移除。这些图片不同于投影背景（显示在项目文字后面）和二维码与短句（也会印在次序单上的小卡片）。

### 二维码与短句

**二维码与短句** 可建立 **新二维码**、**新图片** 和 **新短句**，用在次序单封底和投影片上（例如奉献链接或 Wi-Fi）。

### 检查资料库

**检查资料库**（在诗歌、礼文和圣经分页）列出各语言内容不一致的诗歌和礼文——某一节或某部分只有一种语言、行数或段落数不同、领会／会众的行次序不同——以及可能重复的项目（标题相同、同一诗本编号用了两次），还有某章经文比其他译本少的圣经译本（通常是节数编排不同，有时是缺少整卷书）。标为 **检查** 的通常需要修正；标为 **备注** 的可能没问题。AI 助手可以和你一起处理（**check_library** 工作步骤）。

### 投影背景

**资料库 → 投影背景** 保存用于单个聚会项目投影片的全屏图片。按 **新增背景…** 上传 PNG、JPEG 或 WebP（最大 10 MB）；每张图片会显示尺寸（比屏幕小时会提醒：宽屏投影机用 1920 × 1080，4:3 用 1440 × 1080），以及有几个项目使用。可 **改名**、**替换**（所有使用它的项目都会换成新图片）或删除；使用已删除背景的项目会改回模板的背景。

## 模板

Canon 有三种模板：**聚会模板** 是建立聚会时的程序起点；**次序单模板** 决定印出的次序单包括什么、样子如何；**投影模板** 决定投影片的样子。三者都在侧边栏的 **策划** 之下。

### 聚会模板 {#service-templates}

[聚会模板](/templates) 是可重复使用的聚会程序：按次序排列的项目，连同时长、岗位和姿势。诗歌和读经的位置留空，每周再填写。

1. 按 **新建模板**——或在满意的聚会中，打开 **输出** 栏的 **⋯** 并选择 **另存为模板**。存成模板的聚会会保留项目、投影模板、次序单模板和所属堂。
2. 填写 **模板名称**（各种语言）和 **说明**，设定 **开始时间**，再按 **添加项目** 加入诗歌、读经、礼文、讲道等，每项填写时长和 **岗位**（由谁带领）。要理问答或其他分部分的礼文可用 **问答**（或 **部分**）选择用哪些，如 `1-4`；诗歌可用 **节数** 只选部分诗节（留空 = 全部）。用模板建立的聚会会从这些开始。
3. 若与教会默认不同，可选择它的 **投影模板** 和 **次序单模板**：用它建立的聚会会先用这些模板（每次聚会仍可另选），例如晚堂中文聚会模板会带出自己的次序单和投影。
4. 按 **使用模板** 即可用它建立新聚会。聚会页面的 **新建聚会** 也会列出这些模板。

卡片的 **⋯** 菜单有 **设为教会默认**（管理员：**新建聚会** 时预先选好的模板，会显示 **教会默认** 标记）和 **归档**（移到页面底部的 **已归档的模板**）。三种模板的归档和删除规则都一样——见下文。

### 模板一览

次序单模板和投影模板都先显示模板一览。每张卡片有一个主要按钮（自己的模板是 **编辑**，内置模板是 **预览**）和 **⋯** 菜单：

- **设为教会默认**（管理员）：聚会若没有另选模板，就会使用这个模板。
- **复制一份来修改** / **复制**：Canon 自带的内置模板不能修改或删除，请复制一份再修改副本。
- **归档**：模板不再出现在聚会策划的列表中（已使用它的聚会不受影响）。已归档的模板在页面底部的 **已归档的模板** 中，按 **恢复** 即可再用。教会默认模板不能归档；把已归档的模板设为教会默认会自动恢复它。
- **导出为文件**：把模板存成一个文件（连同背景图片，或页面要印的二维码和图片），可复制到另一台电脑或与其他教会分享。在页面顶部按 **导入模板文件…** 会把它加为新模板；所需的二维码与短句若资料库中没有同名的，会自动加入。
- **删除**（管理员）：只能删除已归档的模板，Canon 内置的模板永远不能删除（只能归档）。请先归档，再在 **已归档的模板** 中删除。使用已删除的投影或次序单模板的聚会会改用教会默认模板；用已删除的聚会模板建立的聚会仍保留原有程序。

编辑页把设定分成可展开的编号步骤，旁边是大的即时预览。修改会立即显示在预览中；按底部栏的 **保存修改** 保留，按 **放弃** 取消。把鼠标移到 **?** 可看简短说明，按 **使用说明** 会回到这里。

### 次序单模板 {#bulletin-templates}

[次序单模板](/bulletin-templates) 决定印出的次序单包含什么。**即时预览** 会逐页显示示例聚会。

1. **纸张与语言**：纸张（通常是 A4 横向对折成 A5 小册子）、字号、印全部语言或只印主要语言、并排或先后排列。
2. **要印出的内容**：各类项目印全部内容、只印第一节，或只印标题／经文出处。
3. **封面与聚会程序**：封面样式、横幅颜色、列表或表格、诗歌编号、姿势、带领者和时间。
4. **页面编排**：按印刷次序排列的各部分：**封面或横幅**、**聚会程序**、**全部内容**（信经、要理问答和诗歌集中印在程序之后）、**报告事项**、**每周内容**、**固定内容**、**今日事奉**、**下周服事**、粗体 **短句**、**二维码、图片与短讯**、**讲道笔记页**，以及 **版权声明与教会联络资料**。**讲道笔记** 可选 **独立一页**、**前一部分下方的余下版面**（例如在报告事项下方印出横线，让会友自己记笔记）或 **只在对折小册子的空白页**。拖动部分（或用 ↑ ↓）调整次序；用 **加入部分 ▾** 和 **加入分页** 增加内容。
   - 每个部分都可以 **另起一页**、**保持在同一页**，或 **放在封底**。封底总是印在最后一页（对折小册子的空白页会加在它前面）。
   - **固定内容**（欢迎词、教会异象、奉献资料）每周相同，在模板中输入；**每周内容**（牧者的话、代祷事项）和 **报告事项** 在每次聚会的 **次序单** 分页输入。

### 投影模板 {#slide-templates}

[投影模板](/slide-templates) 决定投影和 **PowerPoint 幻灯片** 下载的样子。预览显示标题页、诗歌、读经和启应文，点选任何一张可放大查看。

1. **颜色与背景**：深色或浅色起点、四种颜色、背景图片及淡化程度。
2. **字体与字号**：先勾选 **此模板的语言**；然后每种语言各有 **字体**（只能用投影电脑上已安装的字体；同一种文字的语言，例如英文和马来文，共用字体）和相对于其他语言的 **大小**——同样字号时中文看起来比英文小，例如设为 115% 就能平衡（较长的内容仍会缩小以符合画面；PowerPoint 下载也用同样的大小）。接着是整体字号、行距和对齐。
3. **每张投影片的内容**：**每张投影的行数**（默认：显示两种或以上语言时每种语言 2 行，只有一种语言时 3 行；经文、信经与祷文中一行即一句；一句可以跨越信经或祷文的好几行，在投影上仍保留原来的换行）。**每张投影字号相同** 让整场聚会的字体大小保持一致。
4. **屏幕比例与页脚**：**宽屏 16:9**（大多数投影机和电视）或 **标准 4:3**（较旧、较方的投影机）；页脚的经文出处、教会名称和页码；姿势提示；**标题投影上的二维码**（次序单链接）：放在哪个角落、大小——**小**、**中** 或 **大**（PowerPoint 下载也按同样方式放置）；以及 **最后一项之后加一张结束投影**，含各语言的 **结束语**（默认“感谢您与我们一同敬拜”）和教会名称。某一周若要不同的话，可在那堂聚会的最后加一个项目。
5. **自定义 CSS（进阶）** 可不理会，也不会套用到 PowerPoint 下载。

> **提示：** FreeShow 的屏幕比例在它自己的输出设定中设定，所以 FreeShow 项目不跟随模板的屏幕比例。

## 会众 {#people}

- [小组与团契](/groups)：委员会、团契、小组、事工和 **事奉团队**。**新增群组**，再 **添加成员**，填写 **职务** 和任期。要保留记录，请填写结束日期或取消勾选 **使用中**，而不是删除。
  - 每个事奉团队同时也是一个 **事奉团队** 群组：群组成员就是团队名单，可像其他群组一样填写职务（**Leader／组长** 即团队负责人）和任期。团队在 **事奉** 页面新增、改名和删除，岗位也在那里设定；在任何一处改名，两边都会一起更新。
  - **带领**：勾选带领这个群组的人（加入时职务为 **组长**、**主席** 或 **老师** 的人会自动勾选）。带领者可以记录群组的聚会——见 [聚会活动](#meetings)。
  - **主日学班** 也是一种群组：老师带领，学生是成员，**年龄** 填写学生的年龄范围。
- [会友](/members)：**添加会友**，填写姓名、**中文名**、**称谓**（弟兄、姐妹、Bro.、Sis.、Rev.……）、联系方式、状态、受洗与入会日期、家庭，以及 **其他资料** 中教会自己的栏位（见下文）。**家庭** 列表会显示每个家庭的成员，方便分辨同名的家庭；列表底部的 **新建家庭……** 可为刚来教会的家庭建立新家庭。**加入一家人**（在 **添加会友** 旁边，以及家庭分页）可在一个表格中加入整个家庭：每人一行——姓名、中文名、在家庭中的身份、性别、生日、状态——以及家庭名称（跟随第一个人的姓）、地址和住家电话；联络资料、受洗等其他资料之后可在每个人的资料中补上。对话框中已输入内容时，按 Esc、点击框外或 ✕ 关闭前会先询问；按 **取消** 则直接关闭。**生日** 分页列出近期生日。“是／否”或“选择”类的栏位可用来筛选列表（**所有会友** ▾）。只读帐户看得到姓名、家庭、小组和生日（月日），但看不到联系方式、备注、年龄或敏感栏位。列表每次显示 100 人（**上一页** / **下一页**）；搜索、状态标签（附各状态人数）和栏位筛选都会查找所有会友。
  - **会友的个人资料（PDPA）**——管理员在会友页面：**个人资料** 会下载 Canon 保存的该会友所有资料（个人资料、家庭、小组、团队、事奉、不在期间、同工记录、帐户、寄出的电邮、谁查看过资料、修改记录，以及聚会上打字写下其姓名之处），可交给本人。**删除…** 在本人要求时删除这些资料：须输入其姓名确认。姓名、联系方式、日期、备注和教会栏位会永久清除；资格、团队名额、不在期间、同工记录和日后的事奉会被移除；帐户取消连结；修改记录（连同归档）也不再保留其资料。过去的轮值表和小组记录保留匿名的“(erased)”，统计仍然准确。聚会和奉献记录上打字写下的姓名（讲员、点算人、签名）作为教会记录保留。备份中的副本会保留到该备份被删除为止。
- [同工](/coworkers)：牧师、长老、执事和同工。**添加同工**，选择人员、**职分 / 职位** 和 **类别**。**加入委员会…** 可标明所属委员会。
- [事奉](/volunteers)：
  - **团队与岗位**：**添加团队**，**添加岗位** 并设定 **每堂所需人数** 和 **合资格人员**。被设为某岗位合资格的人会自动加入该团队的名单（事奉团队群组）。
  - **事奉表**：选择期间，按 **自动编排** 公平地填补空缺，点击名字更改状态，**打印**。
  - **不便事奉**：为外出的人 **登记不便日期**，自动编排会跳过他们。

## 从 Excel 导入

大多数名单都有 **下载模板**、**导出（Excel）** 和 **导入…**。

1. 按 **下载模板**（Excel 文件）并填写。
2. 直接保存（.xlsx）即可，也可以用 CSV 文件。
3. 按 **导入…** 选择文件。此时尚未保存：预览会显示 **新增**、**将更新**、**没有变动** 和 **有问题** 的行。
4. 按 **导入 N 行**，或 **导入有效的行并跳过错误**。

> **提示：** 同一个文件导入两次也没问题：已有的记录会被比对并更新，不会重复。

**导出的都是 Excel 文件。** 每个列表、报表和记录都下载为 .xlsx 文件。表格上方有标题区：
- 教会名称和文件内容；
- 选择的期间和筛选条件；
- 导出时间和导出者（及其角色）；
- 含会友或新朋友个人资料时会有提示。

标题行已冻结并有筛选。导出的列表可以原样再导入（连同标题区）。只有在其他程序要读取文件时才保留 CSV：给会计软件的分录，以及圣经经文。

导出和导入与画面一样遵循帐户的权限：限定于某个堂的帐户只会导出、预览和更新该堂（以及全教会）的人；看不到敏感会友栏位的角色不会有这些栏位——它导入的文件中若有这类栏位会被忽略，已保存的值保持不变。

## 聚会记录 {#service-records}

[聚会记录](/records)（侧边栏 **记录** 之下）保存每次聚会的情况：出席人数、新朋友、给同工的备注和奉献。列表显示最近 8 周、6 个月或 12 个月（若教会有几个堂，也可按堂筛选），并显示平均出席人数、新朋友人数和奉献总额。点选某次聚会即可打开它的记录。**聚会 / 聚会活动** 可在主日聚会和群组的聚会活动之间切换（见 [聚会活动](/meetings)），所以小组的人数不会拉低主日的平均出席；不收奉献的聚会活动显示 **不收奉献**。

- **出席**：**出席人数**（成人和儿童）、**其中儿童**，如有直播则填 **线上** 人数。
- **新朋友**：姓名、联络资料、**如何来到**、**跟进同工**、**跟进**（新朋友、已联络、再来、已加入教会）和备注。新朋友的资料属个人资料：只记录教会跟进所需的资料。
- **给同工的备注**：做得好的地方、要改进的地方、代祷事项。
- **奉献**：每个奉献项目和方式一行（现金、支票、银行转账、PayNow、刷卡），并按方式显示小计。管理员在 **设置 → 奉献** 设定货币和奉献项目。可以查看但不能更改奉献的角色，在这里看到的是只读内容；聚会带领者可记录自己聚会的奉献（记录列表和 AI 助手也一样）。
- **其他货币**：若收到其他货币的奉献（例如新币教会收到一张美元纸币），把那一行的 **货币** 改为该货币（选 **其他…** 可输入任何三个字母的代码，例如 THB）。每种货币分别合计，不作兑换：列表和总额显示教会的货币，其他货币列在下面（“+ USD 20.00”）。
- **现金点算**：输入每种纸币和硬币的数量，Canon 会自动加总，并显示与现金奉献的差额。其他货币的现金另有点算（**USD 现金**；Canon 没有面额的货币则直接输入 **点算总额**），并可选填 **兑换后价值**（折合教会货币，供司库参考，不计入总额）。每种货币的点算都必须与它的现金奉献相符。
- **点算签名方式**：管理员在 **设置 → 奉献** 选择点算同工如何签名，以及 **最少点算人数**（默认 2 人；更多人一起点算和签名也可以）：
  - **纸本签名**（默认）：填写至少达到最少人数的 **点算同工** 和 **点算日期**（从日历中选择；留空则使用聚会日期），打印声明让他们签名——姓名和日期已印好——再按 **标记为已点算并确认**。
  - **屏幕签名**：每种货币的点算都相符后，每位点算同工输入姓名，用手指、触控笔或鼠标在记录上签名（**签名确认点算**）。签名人数不限。所有人签好后（至少达到最少人数），按 **完成——所有点算同工已签名** 确认点算。签名只对应那一次现金点算：若管理员重新开启点算，或在完成前现金有改动，签名会被清除，点算同工需要重新签名。
  - **点算同工以本人帐户核准**（配合 **屏幕签名**）：每位点算同工不画签名，而是以本人的 Canon 帐户登入，按 **以我的帐户核准**。在同一部设备上轮流画的签名，无法证明是不同的人点算；不同帐户的核准则可以，所以开启这项设定后，只有这种核准计入最少人数。记录和点算声明都会显示每位同工的签名方式。

  确认之后，现金对所有人都锁定：现金奉献行、点算的纸币硬币、点算同工和日期。其他方式的奉献仍可加入——例如之后才收到的银行转账。如需更正现金，由管理员按 **重新开启现金点算**，修改后再次确认（或签名）。出席人数、新朋友和备注仍可更新。
- **删除**：有记录的聚会不能删除，以免出席和奉献资料意外丢失。若记录输入错误，管理员可在记录页按 **删除记录**（已确认的点算须先重新开启）；修改记录会保留一份副本，奉献资料完整保存。
- **打印现金点算声明** 会打印一页 A4：点算明细（每种货币分开）、按方式的总额、简短声明，以及点算同工的签名——屏幕上签的签名，或纸本签名用的空白姓名、签名和日期栏。使用屏幕签名的教会，在还没有人签名之前，也可以打印空白栏作为备用。

只读用户只能看到出席人数和备注，看不到奉献和新朋友的联络资料。新朋友告诉教会的资料（联络资料、代祷事项、备注）取决于角色是否 **可查看会友资料**，奉献则取决于 **奉献** 权限——两者各自独立：文书可以记录新朋友而看不到奉献，财务看得到奉献而看不到新朋友的资料（保存记录时，绝不会改动它看不全的新朋友资料）。每项修改都记在 **设置 → 修改记录**（管理员在记录上按 **修改记录** 可只看这次聚会的修改）。

## 新朋友表格 {#visitor-form}

新朋友可用手机填写一份简短表格，让教会知道他们来过：**姓名**、**电话或电邮**（可不填）、**哪一项最适合形容您？**（可不填——例如慕道友、已信主未受洗、已受洗的基督徒、路过或旅行中、寻找教会）、**您怎样知道这个聚会？**（可不填——例如亲友邀请、路过、社交媒体，或 **其他** 并自行填写）、**我希望教会有人与我联络**，以及（若教会提供）**代祷事项**（可不填）。留下联络资料或代祷事项时，必须勾选同意教会保存这些资料。

1. 管理员在 **设置 → 新朋友表格** 中开启，并可更改 **欢迎词**、**同意声明**、**哪一项最适合形容您？** 的选项（全部删除即不问这一题）和 **您怎样知道这个聚会？** 的选项、是否提供代祷事项栏，以及聚会后几天内仍接受填写（从聚会前一天开始）。所选的答案会以教会的第一语言保存，让新朋友报表把相同的答案合计在一起；同工在记录中填写 **如何来到** 时也会看到这些选项作为建议。
2. 在聚会的 **新朋友表格** 分页为这次聚会开启表格，并选择二维码出现在哪里：**在次序单封底印出二维码**、**在报告事项之后的投影片显示二维码**，或 **打印卡片**（每张 A4 八张，放在招待处或座位上）——可选其一或全部。
3. 提交的资料不会直接加入记录，而是在 **待审核的新朋友卡** 中等候（在聚会的新朋友表格分页和聚会记录中都看得到；记录列表会显示等候的数目）。按 **接受** 会把新朋友加入这次聚会的 **新朋友** 名单（注明“via visitor form”，并附上代祷事项）；按 **舍弃** 可删除垃圾或重复资料。

```flow
[管理员] 启用表格（设置 → 新朋友表格）
[编辑] 为某次聚会启用：二维码印在程序单上、放在幻灯片上，或印成卡片
[新朋友] 用手机扫码并填写表格
表格在 **待审核的新朋友卡** 中等待
**接受**：加入该聚会的新朋友 | **放弃**：删除
```

这份表格是公开网页：任何人只要有聚会的链接或二维码，不用登入就能打开，所以手机必须连得到 Canon——请在 设置 → AI / MCP 设定 **公开网址**。没有公开网址时，链接会使用这台电脑在教会网络上的地址，只能在教会网络中使用（若这台电脑没有网络地址，分页会提醒你手机无法打开）。网页只显示教会名称和聚会的名称与日期，不含任何程序码，并会拒绝填写太快、同一地方提交太多次或不在开放日子内的资料。联络资料、代祷事项和新朋友如何形容自己都属个人资料（PDPA）：只读用户看不到；AI 助手只在 设置 → AI / MCP 的 **新朋友** 设为 **含联络资料** 时才看得到；新朋友报表只显示每个答案的人数（**他们是谁**，只限编辑和管理员）。同一个地方（例如教会的 Wi-Fi，所有手机共用一个网络地址）10 分钟内最多可提交 40 份。

## 报表 {#reports}

[报表](/reports)（侧边栏 **记录** 之下）汇总一段期间：选择 **最近 3 / 6 / 12 个月**、**今年**、**去年** 或 **自选日期…**；若教会有几个堂，也可选择某个堂。除非选择 **聚会活动**（以及某个群组或 **所有群组**），报表只计算主日聚会；事奉和会友统计始终是关于主日聚会和会友的。**打印** 会打印画面上的报表；每个表格的 **CSV** 按钮可下载给 Excel 使用。

- **出席**：平均出席、去年同期（及增减百分比）、最高的一次、儿童和网上人数、每次聚会的图表（虚线为四周平均），以及每月和每个堂的平均。
- **奉献**（编辑和管理员）：按奉献项目和月份、按奉献方式的总额（教会的货币）；其他货币分开列出，不作兑换；尚未确认的现金点算及已等候的天数。**给司库的每月汇总** 打开某个月的一页 A4：按项目和方式的总额、每次聚会及其现金点算、其他货币，以及签名栏。
- **新朋友**：来了多少人，其中多少人已联络、再来、加入教会（在每次聚会记录的 **跟进** 中设定），他们怎样来到教会，以及每月人数。这些数字是按聚会记录中的条目计算的：同一个人在两次聚会都被记录，就算两次，因为 Canon 不会把不同聚会的新朋友连起来。只读用户只看到姓名。
- **事奉**：每人事奉（及婉拒）的次数、没有被安排的团队成员，以及 **难以安排的岗位**——某些聚会人手不足，或合资格的人太少。
- **诗歌**：每首诗歌唱过几次、版权和 CCLI 编号（可导出作版权使用报告），以及期间没有唱过的诗歌。
- **经文**：圣经每卷每章排成小方格——聚会中读过的章为蓝色，讲道讲过的章为金色，两者都有的一半一半，次数越多颜色越深。点选方格可看日期。可选择一个或多个 **年份**（不必相连，例如 2023 和 2025）代替期间；勾选 **只显示有读经或讲道的书卷** 可缩短列表。总数显示教会已读过或讲过圣经（及新旧约各自）的多少，方便规划尚未涉及的书卷的系列。
- **会友**：会友和常来聚会者，按身份、年龄、性别和堂区分，以及期间加入或受洗的人。
- **场地**：期间内教会各场地的使用情况（聚会、聚会活动、活动、时数），所有 **重复预订**（同一场地时间重叠；聚会按程序的分钟数计算，聚会活动或没有程序的聚会算一小时，没有时间的活动算全天），以及不论所选期间、**未来 4 周** 的所有预订。

## 图书馆 {#lending-library}

[图书馆](/lending) 用来管理教会借给会友的书籍、光碟和教材，与收录诗歌、礼文和圣经的 **资料库** 是分开的。这是 Canon 的可选功能：管理员在 **设置 → 功能模块** 中开启后，会出现在侧栏的 **资源** 下。内置的 **图书管理员** 角色可以使用这里的所有功能，但看不到会友名册；借阅者只按姓名选择。

**目录**
- **新增书籍**：输入或扫描 **ISBN**（书背条码上的号码），再按 **查询**。Canon 会从 Open Library（找不到时从 Google Books）填入书名、作者、出版社、年份和封面；只会送出 ISBN。没有网络或书籍没有 ISBN 时，请自行输入资料。选择 **类别**（书、光碟、教材）、**分类**、**语言** 和 **书架**，并填写 **副本** 数。
- 按 **保存** 后，新书会连同其副本再次打开，方便直接 **打印标签**。
- 每册都有编号（**B0001**、**B0002** ……）。**打印标签**（在书籍中，打印所有副本）可把二维码标签印在 **A4 标签贴纸**（每张 24、21 或 65 个；**从第几个标签开始** 可用部分用过的贴纸）或 **标签打印机**（62 × 29 毫米）上。标签上有二维码、编号、书名和书架。请以 100% 比例打印。二维码会以办公室电脑的网络地址在 Canon 中打开该册书，手机须连上教会网络。
- 副本可标记为 **遗失** 或 **已注销**；从未借出的副本可以删除。
- **导入…** 可一次导入整份书单（每行一个书目，并注明册数）；**导出（Excel）** 可导出目录。

**借出与归还**：输入副本编号（或用扫描器扫描二维码标签），再按 **查找**。
- **可借**：选择 **借阅者**（输入部分姓名；只限会友），确认 **归还日期**（按 **借阅规则** 的借期），再按 **借出**。
- **借出中**：按 **收回**，或按 **续借** 再延长一个借期（不超过允许的续借次数）。
- **借阅者已归还**（借阅者在手机上告知）：书上架后按 **登记归还**；这时不能续借。
- 用手机相机扫描标签也会打开同一张卡片。
- **有 Canon 帐户的会友** 在登入状态下扫描标签，可以用自己的身份借书——**借这本**（显示其名字）、**我要归还**——不需要电邮验证码，前提是自助借阅已开启（帐户须连结到其会友资料）。可以办理借出的人会在上方另外看到柜台卡片，用来借给别人；自己借则在 **我自己借** 下面。

**借出中** 列出所有借出的物品，逾期的排在前面（**逾期** 和 **已归还** 分别列出）。会友若还有物品未归还，在归还之前不能删除，也不能删除其个人资料。

**借阅规则**：**借期**、**可续借次数** 和提醒时间。勾选 **每天以电邮发送提醒** 后，有电邮地址的借阅者会收到以其语言写的电邮：在到期前所设定的天数收到一次「即将到期」，逾期后每周收到一次「已逾期」。使用教会的电邮帐户（设置 → 电邮）。借出中分页的 **立即发送** 可马上发出今天的提醒。

**自助借阅**（借阅规则）：会友用自己的手机借书、续借和告知归还，不需要 Canon 帐户。
- **借书**：扫描书上的二维码标签，按 **借这本**，再用寄到会友名册电邮地址的 6 位数验证码登入（可直接从电邮贴上，包含空格也可以）。验证码只能用一次，10 分钟内有效；登入后在该手机上约两小时有效。不在名册中、或由多人共用的电邮地址不会收到验证码；页面不会透露是哪一种情况。
- **续借**：在同一页的 **我的借阅** 中续借（会显示还可续借几次），或按提醒电邮中的 **在线续借** 链接。打开链接不会改变任何内容；按页面上的按钮才会续借。
- **归还**：在书的页面或 **我的借阅** 的该笔借阅旁按 **我要归还**，借阅会标记为“已归还：等候图书管理员登记”，并显示在 **借出中 → 待登记归还**（首页也会显示），图书管理员确认书已上架后按 **登记归还**。期间不会再发提醒。
- **检查项目**：只有所有检查都通过时才能开启自助借阅：**电邮正常**（自上次更改电邮设定以来，已在 设置 → 电邮 成功发送测试电邮）、**可连到这个 Canon 的公开 https 网址**（设置 → AI / MCP；Canon 会经由该网址呼叫自己来确认），以及 **图书馆已开启并已保存借阅规则**。之后若有检查失败（电邮无法发送、网址无法连通），自助借阅会自动暂停：手机会提示找图书管理员，检查再次通过后会自动恢复。按 **再检查一次** 可立即检查。
- 开启后请重新打印标签：新标签使用公开网址，离开教会 Wi-Fi 也能使用。安全与隐私检查表会显示自助借阅已开启，以及本周寄出了多少个验证码。

## 资产登记 {#asset-register}

[资产登记](/equipment) 用来管理教会的设备与财产。这是 Canon 的可选功能（**设置 → 功能模块**），位于侧栏的 **资源** 下。内置的 **资产管理员** 角色负责管理。

- **新增物品**：**名称**、**资产编号**（留空则使用下一个编号，**E0001** ……）、**类别**、**品牌型号**、**序号**、**存放地点**、**负责人**（会友，按姓名选择）、**状况** 和 **状态**（使用中、存放、停用）。在 **购买** 下：**购买日期**、**价格**、**供应商** 和 **保修期至**。
- **照片与收据**：可加入照片（PNG、JPEG、WebP）和 PDF 收据或保修单，每个最大 10 MB。文件存在 Canon 的数据库中，所以备份也会包括它们。
- **保养**：**每隔（月）** 和 **下次保养**。在 **保养记录** 中按 **记录**，写下做了什么、日期、由谁做和费用；设定了固定周期时，下次保养日期会顺延相同的月数。列表中的 **需要保养** 显示两周内到期或已逾期的项目，首页也会显示数量。
- **打印标签** 可为列表中的物品打印二维码标签，方式与书籍相同。二维码会打开该物品：它是什么、放在哪里、由谁负责。
- **导入…** 可导入现有的清单（每行一件物品）；**导出（Excel）** 可导出资产登记。

## 财务账簿 {#bookkeeping}

[财务账簿](/bookkeeping) 是教会的复式记账账簿。这是 Canon 的可选功能（**设置 → 功能模块**），位于侧栏的 **财务** 下。由 **财务** 角色记账。**牧师 / 长老** 和 **外部访客**（例如核数师）可以查看。编辑、聚会策划、文书和只读帐户看不到，除非你修改他们的角色。

账簿采用 **收付实现制**：钱收到或付出时才记账。需要时，也可以用分录记录应收应付（应计）。金额以教会的货币计算（设置 → 奉献）。分录的每一行都属于一个 **款项**。一行也可以标上 **项目**、**事工**，有多个会众的教会还可以标上 **会众**。

**开始记账**
- **开始记账**：选择账簿开始的日期（通常是财政年度的第一天）和财政年度结束的月份。勾选后，Canon 会提供教会 **会计科目表** 和四个款项：常费（非限定用途）、宣教（指定用途）、建堂和慈惠（限定用途）。可在 **科目与款项** 中改名、增加或停用。
- **期初余额**：录入开始日期当天教会的资产和负债：银行和现金余额、押金、应付款项等。然后录入这些在各款项之间的分配。**余额归入常费** 会补上差额。**保存并过账** 把它记为一笔分录。日后如需更正，冲销后重新录入。

**分录**
- **新分录**：日期、摘要和各行。每一行有科目、款项、借方或贷方金额，以及可选的项目、事工和备注。
- **保存草稿** 留待稍后完成。**保存并过账** 会先检查：
  - 借贷必须相等；
  - 日期不能早于账簿开始日期，也不能在已关账的期间内；
  - 科目和款项必须是使用中的。
- **已过账的分录永远不会被修改。** 它会得到一个编号（例如 2026-0042）。出错时用 **冲销…** 更正：
  - Canon 会在你选择的日期起草一笔冲销分录，每一行借贷对调。原来已过账的分录保持不变。
  - 检查草稿（可以更改日期和摘要），然后过账。过账后两笔才会连在一起，互相抵销。删除草稿则什么都不会改变。
  - 如有需要，再正确地重新录入。
  - 开放财务账簿的 AI 助手也可以按分录编号起草冲销分录；由你过账。
- **草稿** 可以来自你、已核实的奉献、银行画面和 AI 助手（标有 **AI 草稿**）。勾选多份后按 **过账所选的 … 份** 一起过账；有问题的会保留为草稿。
- **导出（Excel）** 可导出一段期间内所有已过账的行。**CSV** 提供同样的内容，给可以导入手工分录文件的会计软件使用。**设置 → 导出资料** 也提供分录、会计科目表和款项，zip 文件中也有。
- **导入…** 从 Excel 或 CSV 文件导入分录：**下载模板**，每行一项，同一笔分录的各行在 **Journal** 栏用同一个编号；科目和款项用代号，项目和事工用代号或名称。另一个 Canon 导出的分录也可以导入。
  - 预览会显示每笔分录，以及有什么问题。
  - 科目或款项不认识、或日期无法读取的分录不会导入。
  - 借贷不平衡的分录会导入，但修正之前不能过账。
  - 全部以 **草稿** 导入：在你过账之前，不会过账任何分录。
- 分录的 **历史记录** 显示过账前后的每一次更改：谁改了什么，以及每一行的科目、款项和金额的修改前 → 修改后。
  - 草稿在过账前都可以修改，但每次修改都有记录。
  - 奉献分录的历史记录还会显示现金点算的更改（金额、点算、核实和重开），以及这场聚会之前被撤回的草稿。

**奉献入账**

```flow
[点算员] 在聚会记录上点算奉献并签名——纸本或在屏幕上
[Canon] 核实后的点算会起草分录：现金和支票记入“未存入银行的奉献”，PayNow 和转账记入银行
[财务] **过账奉献草稿**
[财务] 把现金存入银行，再导入银行对账单
[财务] 把存款（以及其他每一笔）与账目配对，并以对账单的期末余额核对
```

- 现金点算 **核实** 后（聚会记录），Canon 会起草分录。每种付款方式记入对应科目：现金和支票记入 **未存入银行的奉献**，PayNow 和转账记入银行。每个款项的奉献记入它的收入科目。
- 重开点算会撤回草稿。更正后的点算只起草与已过账金额的差额。
- 点算核实后才加入记录的 PayNow 或转账，也会起草分录（只起草新增的金额）。
- 在聚会记录的现金点算下方，**账簿** 一栏会显示它的分录是等待过账的草稿，还是已过账（附编号）。点击即可打开该分录。
- **奉献入账 → 更改** 设定每种付款方式使用的科目，以及每个奉献项目对应的款项和收入科目。
- **过账奉献草稿** 一次过账这周的奉献草稿。**起草缺少的分录** 为账簿开始前已核实的奉献起草分录。
- 外币现金按 **兑换后的金额** 入账，原币金额保留在该行。

**银行**
- **导入对账单**：从银行网站把对账单导出为 CSV 或 Excel，然后选择文件。
  - Canon 会找到栏名所在的行，猜测各栏（日期、说明、一个金额栏或支出 / 存入两栏）和日期格式。请检查；该银行账户会记住这些设定。
  - 已导入过的行会被跳过。对账单可以重叠：文件有银行参考编号时，编号相同才算同一笔交易；没有编号时，会计算相同日期、金额和说明的行数，所以真正的第二笔相同金额奉献仍会导入。
  - 录入对账单的期初和期末余额才能对账。
- 把对账单的每一行与账簿 **配对**：
  - **配对明显的项目** 会配对同一天恰好只有一笔相同金额分录的行；
  - 建议项（一周内相同金额）按一下即可配对；
  - **成组配对**（合计相符时）：
    - 几行对账单对应一笔分录，例如 25 和 35 的两笔 PayNow 奉献对应该聚会奉献的一行 60；
    - 或一行对账单对应几笔分录，例如一笔现金存款包含两场聚会的奉献。
    - Canon 会建议找到的组合（一周内最多四行）。也可以勾选几行，按 **把勾选的 … 行一起配对…**，再勾选对应的分录。
    - 在组内任何一行按 **取消配对**，整组都会取消。
  - **录入** 把账簿中还没有的项目（银行手续费、利息、自动扣款）记入你选择的科目和款项，并完成配对；
  - **奉献…**（存入）：在对账单上才看到的 PayNow 或转账奉献。选择聚会（Canon 列出之前两周内的聚会，最近的在前）、奉献项目和方式。
    - Canon 会把它加入该聚会的奉献，聚会记录和 报表 → 奉献 也就会有这笔。现金点算核实后也可以加入：锁定的只是现金。
    - **加入、过账并配对** 一步完成过账和配对。如果该聚会的现金点算还没有核实，会在核实后起草分录。
    - 不属于任何聚会的奉献（每月定期转账、捐款）请用 **录入**。
  - **忽略** 把一行搁置。
  - 已经为它准备了草稿的行（通过 **录入 → 保存草稿**，或由 AI 助手起草）会显示 **草稿待过账**。过账该草稿时，这一行就会配对。
  - 每次配对、取消配对和忽略都会记入修改记录。
- 上方的 **对账**：账面余额减去尚未出现在对账单上的项目，应等于对账单的期末余额。**差额** 为 0.00 表示账簿与银行一致，这时可按 **标记为已对账**。
  - 只计算到对账单最后一天银行已结清的项目：在下个月对账单上配对的支票，在本月的对账中仍算作未兑现，所以已对好账的月份不会改变。
  - 已配对的交易要先取消配对，才能配对到别的项目。
  - 用逗号作小数点的金额（`1.234,50`、`12,50`）会按原意读取。
  - 若对账单中的交易已加入聚会的奉献，这份对账单就不能删除（再次导入时，同一笔奉献可能会被加入两次）。

**报表**：只根据已过账的分录。每份报表都可以 **打印**（附教会名称和期间）或下载为 Excel，标题区会注明期间和筛选条件。
- **收支表**：一段期间的收支，按款项分栏，也可只看一个款项、项目或事工。
- **资产负债表**：某日教会的资产和负债，以及各款项的余额。
- **款项变动表**：各款项的期初余额、收入、支出、转拨和期末余额。
- **试算表**：某日每个科目的余额。
- **按项目**、**按事工**、**按会众**：各自的收入、支出和净额。
- **科目明细账**：一个科目的每笔记录及累计余额。点击一笔记录可打开它的分录。
- 不需要年终结账分录：每年的盈余留在各自的款项里。

**关账**：某月或某年核对完毕、银行对账后，按 **关账** 关至该期间最后一天。此后该日期或之前的分录都不能再过账。该期间内的草稿必须先过账、改日期或删除。管理员可以 **重新开启**。

**科目与款项**：
- **会计科目表**：代号、名称和类型（资产、负债、款项、收入、支出），以及 **用途**：银行账户、现金、未存入银行的奉献、外币现金、款项余额、款项之间的转拨或其他。
- **款项**：非限定用途、指定用途（教会自己拨出）、限定用途（奉献者指定）或永久保留款项。
- **项目** 和 **事工**：用来标记分录行。
- 已在分录中用过的可以改名或停用，不能删除。
- **导入…**（会计科目表、款项）：**下载目前的清单**，在 Excel 中修改或增加行，再选择文件。按代号比对：新代号会加入，已有的会更新。预览会先显示每项更改。不会删除任何项目，已使用的科目会保留原来的类型。

**AI 助手**：在 **设置 → AI / MCP** 中开放财务账簿后（默认关闭），AI 助手可以查看账簿和报表，也可以 **起草** 分录，例如根据你贴上的收据。它永远不能过账、冲销或修改已过账的分录。每份草稿都由人审阅后在 Canon 中过账。
- 它也看得到你导入的 **银行对账单** 和待配对的行。可以请它“为十月对账单上的银行手续费和利息起草分录”：草稿会挂在这些行上（**草稿待过账**），过账时自动配对。
- 导入对账单和配对仍由你来做。

**首页**：能查看账簿的人会看到 **财务账簿** 卡片，显示待过账的草稿（其中多少是奉献）、待配对的银行交易，以及待审批或待付款的报销。

### 报销申请 {#claims}

任何人都可以申请报销为教会支付的费用，**一份报销可以有几张收据**：用手机，或在侧栏 **财务** 下的 **我的报销**。

```flow
[申请人] 列出所付的费用、每张收据的照片、还款到哪里——然后签名 | [办公室] 或录入纸本报销，附上收据和签了名的表格
[批准人] 逐项核对收据
**核准**（签名；超过设定金额需两位批准人） | **退回**：申请人修改后再签名 | **拒绝**，并说明原因
[Canon] 起草支出分录：借 支出 / 贷 应付报销
[财务] 还款给申请人（例如 PayNow），然后按 **付款…**：Canon 起草 借 应付报销 / 贷 银行
[财务] 在 **分录** 中把两笔过账；银行对账单上的那一笔会被配对
```


**申请报销**
1. **新报销申请**：写下用途，如果属于某个事工，也选择事工。
2. 每张收据一项：用途、收据日期、金额和商店。**拍照加入收据** 会打开手机相机，也可以用 PDF。**再加一张收据** 增加一项。一项可以有几张照片（分段拍的长收据，或收据连同发票）。办公室也可以附上不属于任何一项的文件，例如签了名的纸本表格。
3. **还款到哪里**，例如 PayNow 号码或银行户口。只有申请人和财务看得到。如果这是由办公室输入，而不是申请人本人（纸本报销，或替申请人修改），批准人会在报销上看到这一点（但看不到内容本身），应向申请人或在其签署的表格上确认款项会付给本人。
4. Canon 会列出还缺什么。都齐全后，用一根手指在框内 **签名**（第二根手指不会画线），再按 **签名并提交**。签名会附上你会友资料中的姓名。报销会得到编号（例如 C2026-0001），可以审批的人会收到电邮。

准备中的报销可以修改或删除。已提交的报销在批准前可以撤回。

**谁登录、怎样登录**
- 已登录 Canon 的人，在 **我的报销** 会以自己的会友身份登录。他的帐户必须连结到会友资料（设置 → 用户帐户）。
- 其他人用手机打开报销链接，用寄到会友资料中电邮地址的验证码登录，和图书馆一样。财务在 **审批人与设置 → 用手机登录** 中开启。这需要电邮可以发送，并有公开的 https 网址。
- **会友用的链接** 提供链接和二维码，可以分享或贴在布告栏。

**审批**
- 审批人是 **指定的人，不是角色**：会友名单上的任何人，有没有 Canon 帐户都可以。在 **财务账簿 → 报销 → 审批人与设置** 中加入。
  - 可以限定审批人只审批某些事工，以及最多多少金额。
  - **超过此金额需两位审批**：较大的报销需要两位不同的人批准。留空就只需一位。
- 审批人从电邮或 **我的报销** 打开报销，逐一核对每张收据和对应的项目，然后：
  - **签名批准**；
  - **退回** 并写下原因：申请人修改后再签名；
  - 或写下原因 **拒绝**。
- **任何人都不能审批或支付自己的报销。** 付款的人如果也批准了这份报销，Canon 允许，但会标示 **审批人付款**。
- 批准只对提交时的报销有效。报销被退回后再次提交，或办公室把等待审批的报销改到另一个事工或项目时，审批会重新开始。
- 审批人用会友资料中的电邮地址登入，所以只有管理员或可以修改账簿的人才能更改这个地址。

**办公室（财务账簿 → 报销）**
- **待审批或待付款** 列出所有报销（限定于某个堂的帐户：该堂以及全教会的报销）。点击可查看收据、签名和审批。收据在报销里的检视器中逐张显示——每张标明属于哪一项（**第 1 项 · 零食**），或 **不属于任何一项**（例如签了名的纸本表格）——用 **‹ ›** 或缩图切换，**实际大小** 可看清小字（在框内滚动），也可 **在新分页打开**。PDF 会在新分页打开。若还款去处由办公室输入，会显示 **由办公室输入**。
- **记账方式**：每一项的支出科目、款项、事工和项目。没有指定的项目会记入默认支出科目（除非另选，否则是科目 5990）。更改记账方式不影响申请人签名的内容。
- **录入纸本报销**：为会友录入交来的纸本报销。附上收据和签了名的表格，然后按 **已在纸本签名：提交**。
- **入账：**
  - **报销批准后**，Canon 会起草支出：借 各项的支出科目 / 贷 **2100 应付报销款**。资产负债表就会显示欠申请人的款项。
  - **付款：**先把钱还给申请人（例如用 PayNow），再按 **付款…**，填写日期、付款的户口和参考编号。Canon 会起草（按 **记录并过账** 则直接过账）借 应付报销款 / 贷 银行。之后对账单上的那笔银行交易会被建议配对。
    - 先有支出：报销的支出过账后，才能 **记录并过账**。若支出草稿不见了（报销在账簿开始前已批准，或草稿被删除），付款时会重新起草。
    - 删除报销的付款草稿后，报销会回到 **已批准**，可以稍后再付款。
  - 每位会友同时最多可以有 20 份正在准备的报销。
  - 和所有分录一样，两笔都由财务在 **分录** 中过账。

**AI 助手与报销**：把收据照片传给 Claude，请它帮你申请报销。
- Claude 会读出商店、日期和金额，每张收据起草一项。
- 它会回复报销的链接：用手机打开，附上收据照片，核对各项，填写还款到哪里，然后签名。
- Claude 不能自己附上照片、提交、审批或付款。
- 只要 AI 连接中的财务账簿设为 **读写**，任何角色都可以使用：每个人只能起草自己的报销。管理账簿的人可以为其他会友起草。

## 设置

打开 [设置](/settings)。管理员会在左侧看到分成四组的各个部分（**我的帐户**、**教会**、**人员与权限**、**Canon**）；在手机上，从顶部的列表选择。

- **我的资料**（所有人；管理员看到的是第一个部分）：显示名称、界面语言、**更改密码**。
- **教会**、**语言**、**用户帐户**、**角色与权限**：见 [开始使用](#开始使用)。
- **场地**（管理员）：教会的礼堂、房间和其他地方——各语言的 **名称**、**容量** 和 **备注**（例如投影机、钢琴）。聚会、聚会活动和日历活动都可选择场地。⋯ 菜单可编辑、归档（已有的预订保留，但不再供新预订选用），或删除从未被预订的场地。
- **导出资料**（管理员）：一键下载 Canon 的各个部分——每个列表的 Excel 文件（可用 **导入…** 再导入），含个人资料的会标明——以及 **下载全部（zip）**，内含所有 CSV 和资料库文件。这不是备份：聚会、记录和帐户只在备份中。
  - **资料库文件**：诗本、诗歌（含歌词、诗本编号和 **乐谱**）、礼文、**二维码与短句**、投影背景和图片（勾选要包含的内容；**你上传的圣经** 只在许可允许分享时才勾选），合成一个 `.canonlib` 文件。在另一个 Canon（其他教会或新电脑）按 **导入资料库文件……**，会先显示将加入的内容，然后只加入对方还没有的：诗歌和礼文按代码或标题配对，诗本按缩写。已有的诗歌只会加入原本没有的诗本编号和乐谱。上传的圣经只在确认教会获准使用时才会导入。
  - **资料库各部分**：同样格式的文件，一次一个部分——**诗歌** 按诗本逐本导出（含歌词、编号和乐谱）、**不属任何诗本的诗歌**、**礼文**、每个你上传的 **圣经**、**二维码与短句**、**投影背景** 和 **图片**。管理员在资料库每个分页也有 **导出** 按钮（诗歌分页会列出各诗本），旁边是 **导入资料库文件……**。
- **功能模块**（管理员；首次设定 Canon 时也会出现）：关闭教会不使用的部分——**聚会活动与日历**、**同工与事奉表**、**新朋友表格**——或开启需要的部分：**图书馆**、**资产登记** 和 **财务账簿** 默认是关闭的。关闭的部分对所有人隐藏（侧边栏、聚会程序的分页、设置和报表），服务器也会拒绝，AI 助手也看不到。不会删除任何资料：重新开启即可恢复一切。
- **会友栏位**（管理员）：会友名册中你自己的栏位——**文字**、**日期**、**是／否** 或 **从列表中选择**（附选项），每个都有教会各语言的名称，例如“小组组长？”、“如何加入”、“饮食需要”。勾选 **敏感** 可让只读帐户和 AI 助手看不到（除非教会开放个人资料）。它们显示在每位会友页面的 **其他资料** 中，可筛选会友列表，也是会友 CSV 中的栏位（`custom_…`）。移除栏位会把它隐藏并保留已填的值：它会列在 **已移除的栏位** 中，按 **还原**（再按 **保存**）即可连同这些值一起恢复。新栏位即使名称相同，也绝不会取代已移除的栏位。已有会友填了值的栏位不能更改类型（Canon 会说明有多少位会友填了值）：请改为新增一个栏位。
- **奉献**（管理员）：教会的货币、奉献项目、**点算签名方式**（纸本或屏幕）和 **最少点算人数**——参见 [聚会记录](#service-records)。
- **电邮**：选择 **电邮服务商**（Gmail、Microsoft 365 或其他），填写 SMTP 资料并 **保存**，再按 **发送测试**。Gmail 须使用应用专用密码。
- **安全与隐私**（管理员）：最上方是 **加密**——教会的资料是否已加密、密钥在这台电脑上如何打开，以及恢复密钥的编号和日期。**另做新的恢复密钥……**（会再次要求输入你的密码）会显示新的密钥一次；旧的密钥之后不能再打开数据库，但请保留它，以还原在那之前做的备份（每份备份都会注明能打开它的恢复密钥）。接着是用简单的话列出的 **安全检查表**——磁盘加密（开启 BitLocker 等之后按 **已完成**；Canon 无法自行侦测）、自动备份及其新旧、备份存放位置、备份加密、公开网址、管理员人数、两步登入、每个帐户是否属于教会会友（或外部访客）、六个月未使用的帐户、AI 助手是否取得会友或新朋友的联络资料、新朋友表格、图书馆的自助借阅（开启时），以及记录保留多久——每项都说明该怎么做。若每日整理有某部分失败（尤其是未能如期删除新朋友的联络资料），**每日整理** 会以警告显示，直到恢复正常为止。下方的 **谁查看了会友资料** 记录每次有人打开会友页面、AI 助手读取会友资料或导出会友名册（同一人同一页面 10 分钟内只算一次），可筛选、**导出（Excel）**，保留期限与修改记录相同。**保留与归档**：**新朋友联络资料保留多久后删除**（默认 24 个月——删除电话或电邮、代祷事项、自我描述和备注；姓名、如何来到和跟进会保留，报表仍可统计）和 **归档多少年以前的记录**（默认 5 年，适用于聚会记录及其奉献），以及 **归档多少年以前的日志**（除非另选年数，否则 **与记录相同**，适用于修改记录、AI 活动和查看记录）。**查看可归档的资料** 会列出符合的整年；**立即归档** 会把这些年份的聚会记录（连同奉献）和日志移到 `data/archives` 中，每年一个只读文件——聚会本身仍会保留。已归档的年份可以 **打开**（聚会记录和修改记录，只读）或 **下载**，每份备份也会一并包含它们（已加密的 Canon 的备份把它们放在同一个文件里）。
  - **归档不会覆盖记录。** 如果还原的备份带回一份也在归档中的记录，只有两者完全相同时才会继续归档；否则会停止，并保留使用中的记录不变。请取回归档中的那份，比较两者。
  - **已归档的记录是只读的。** 它的聚会在聚会记录中显示 **已归档**。任何人都不能为它新增记录、删除这次聚会或把它改到别的日期。要更正已归档的记录，打开那一年并按 **取回**：记录会回到聚会记录中（会记录在修改记录里），下次归档时会再次存入归档。
  - **删除新朋友资料会处理 Canon 保留的每一份副本：** 聚会记录、归档文件和修改记录，包括之后被删除的聚会的修改记录。归档前会先删除，所以过期的资料不会进入归档。备份中的副本会保留到该备份被删除为止（设置 → 备份 → 保留最新的份数）；还原备份后会立即再次删除。
  - **修改记录的保留期限照样适用：** 如果它比归档年限短，日志会在够旧可以归档之前就被删除，这里会提醒你。若希望归档也包括修改历史，请把修改记录保留久一点。
  - **报表只计算未归档的记录：** 所选期间包括已归档年份时，报表页会注明是哪几年。
- **示例数据**（管理员）：**加入示例教会** 会在 Canon 中加入一间虚构的教会，方便试用——约 40 人分属各家庭（丈夫、妻子和孩子），每人都有英文名和自己的中文名（不是翻译）以及生日；按地区分的小组（东区、西区、北区和青年）、四个委员会、两个团契和主日学；每个事奉团队也有人。勾选 **也把他们排进事奉表……** 会填上下一堂聚会以及一周后其副本的空缺，让次序单的 **下周服事** 和团队分享页有名字。勾选 **也加入教会的活动……** 会填满 Canon 已启用的每个部分（设置 → 功能模块），让你看到它们如何一起运作：用 Canon 的聚会模板建立过去八个和接下来两个主日的聚会（如果还没有 Canon 自带资料库，会先加入），附事奉表和聚会记录——出席、新朋友，以及已点算并核实的奉献；小组和主日学的聚会活动及其记录；日历上的活动和场地（教会还没有场地时）；图书馆书籍和借阅（两本逾期）；有负责人和保养记录的资产登记；以及在账簿尚未开始时的账簿本身——期初余额、已过账的奉献、存入银行的现金、每月开支、已配对的银行对账单（留一笔待配对），以及准备中、待审批、退回、已核准和已付款的报销。每位示例人员的备注都会注明。**移除示例数据** 只会删除当初加入的内容——这些人以及他们在小组、团队和事奉表中的位置、他们的家庭和小组、聚会和聚会活动及其记录、活动、场地、书籍、资产、分录、银行对账单和报销——不会删除任何人输入的资料（已有真实会友加入的小组会保留）。如果账簿是由示例开始的，而里面没有真实资料，账簿会回到尚未开始的状态。
  - 已有真实记录的示例资料会保留，Canon 会列出来：聚会记录被人改过、或有真实分录的示例聚会；被真实分录冲销、或与真实银行对账单配对的示例分录；有真实预订的场地；以及连结到帐户、有真实借书或报销的示例人员。
  - 已过账的分录永远不能删除——只有示例自己的分录，会在移除示例时删除。
  - 只会移除仍标记为示例的资料，所以绝不会误删真实会友。
- **修改记录**（管理员）：在 Canon 中、通过 AI 助手或导入所做的每项修改——谁、何时、以什么方式，以及每个栏位的旧值 → 新值。可按内容（会友、聚会、诗歌……）、人员、方式、新增／修改／删除、日期或文字筛选，并翻阅较旧的记录。**导出（Excel）** 会下载符合筛选条件的所有记录（最多 20,000 条），可用 Excel 打开。**保留** 设定保存几个月（较旧的记录每天删除一次）。密码绝不会被记录，任何被命名为机密的内容（令牌、密钥）也不会，即使是在某个值里面。Canon 自己做的事——每日整理（删除新朋友资料、预先建立聚会）、自动备份、更新——会显示为 **Canon** 所做。修改记录和 AI 使用记录的 Excel 导出会注明含有个人资料。会友资料中的 **修改记录** 按钮显示该会友的修改。
- **AI / MCP**：见下文。

## AI 助手

Canon 可以连接 Claude（claude.ai），你可以请它“按罗马书 8 章策划下主日的聚会”，或问“事奉表还缺哪些人？”。

### 连接 Claude

1. Claude 需要一个 **https** 公开网址才能连到 Canon，通常由负责电脑的同工设定隧道（tunnel）。
2. **设置 → AI / MCP**：开启 **启用 MCP 服务器**（立即生效；关闭时会先询问，因为所有已连接的 AI 助手都会失去存取权），贴上 **公开网址**，按 **检查**，再按 **保存**。
3. 在 **模块权限** 为每个模块选择 **关闭**、**只读** 或 **读写**，然后在有未保存更改时固定在窗口底部的栏中按 **保存 AI 权限**（各模块的权限会一起保存，方便您先检查）。**聚会记录**（出席、新朋友姓名与跟进、备注）及其下的 **奉献** 默认关闭，需要你开启；奉献永远只能读取——Claude 不会更改金额、签名或确认点算，只读帐户也永远看不到奉献。
   两个个人资料开关放在所属模块之下（模块关闭时也一并关闭）：
   - **会友名册 → 联络资料与生日**（**关闭** 或 **提供**）：会友的电话、电邮与住址、出生日期、备注和请假原因，以及同工和家庭的联络资料。默认关闭。
   - **资料库 → 乐谱**（**关闭** 或 **提供**，默认关闭）：Claude 可列出聚会诗歌及其乐谱，并阅读扫描页面（例如“主日哪首诗歌最高音？”）。这些页面会成为 AI 服务商处的副本：只有在教会可以复印该乐谱时才提供。PDF 不会传送。Claude 无法自己上传文件，但资料库设为 **读写** 时，它可以给你一首诗歌的上传链接（“为 HP 178 加入乐谱”）：用手机打开链接加入页面。
   - **聚会记录 → 新朋友**：**关闭**（只有出席人数；Claude 不能记录新朋友）、**姓名与跟进**（姓名、如何来到和跟进情况；选择“读写”时 Claude 可新增新朋友和更新跟进，但不含联络资料）或 **含联络资料**（另加电话或电邮和代祷事项——只有在已取得新朋友同意、可与 AI 服务商分享时才选择）。0.15.1 之前已开放个人资料的教会从 **含联络资料** 开始，其他教会从 **姓名与跟进** 开始。
4. 在 claude.ai：**Settings → Connectors → Add custom connector**，贴上 **连接器网址**，client ID 留空，登入 Canon 并批准。该页面会显示这个连接能接触到什么：每个模块按你的角色所允许的程度（只读帐户绝不会看到 **读写**）、在“设置 → 功能模块”中关闭的部分不会出现，而联系资料只在你的角色看得到时才会列出。

Claude 还会得到现成的工作步骤（策划聚会、推荐诗歌、检查事奉表、校对程序、编排要理问答进度、导入现有的次序单或投影片、为领袖撰写每月报告……）。导入时，把现在用的次序单（PDF、Word 或照片）或 PowerPoint 交给 Claude：它会把诗歌和礼文与资料库对照，建立聚会让你检查，并列出在模板编辑器中要选的设定。

Claude 会先参考你们过去的聚会：去年同一主日、同一节期、以前讲同一卷书的主日、每首诗歌上次何时唱过、要理问答讲到第几问。它会按照教会惯常的程序、诗歌和事奉安排，避免重复最近几周唱过的诗歌，并说明它的建议参考了哪几堂聚会。

### Claude 看得到什么

- 它只看得到你开放的模块，并以批准连接的那个人的身份操作。只读帐户的连接永远只能读取。
- 除非会友名册下的 **联络资料与生日** 设为 **提供**（且会友名册已开启），会友的联系方式和生日都不会显示；新朋友的联络资料只在 **新朋友 → 含联络资料** 时提供。由只读帐户批准的连接，无论开关如何，都永远拿不到联络资料——最多只看到新朋友的姓名。
- 它不能发电邮或删除人员。更改资料前它会先询问。
- 在 **设置 → 功能模块** 中关闭的部分，Claude 也看不到：相关工具、需要它的操作指南，以及（义工模块）每场聚会由谁事奉。没有开放联系资料时，Claude 只按姓名搜索会友，也不能更改它看不到的联系资料；会友统计只提供数字，不列姓名；回答过大时（多年的出席、所有聚会）会被拒绝，并说明要如何缩小范围。
- **财务账簿**（默认关闭）：Claude 可以查看账簿、报表和导入的银行对账单，并 **起草** 分录让财务过账——包括账簿中还没有的对账单项目。即使是 **读写**，它也只能起草：永远不能过账、冲销或修改已过账的分录，也不能导入对账单或配对。
- **管理**（默认关闭；只限由管理员批准的连接）：**只读** 让 Claude 读取安全检查表、备份、帐户（绝不含密码）、修改记录、谁查看了会友资料和设置概览——例如问“这周有什么要处理的？”或“谁改了主日的程序？”。**读写** 另加两个操作：立即备份，以及执行检查（公开网址、备份文件夹、电邮）。帐户、角色和设置只能在 Canon 中更改。只有在提供会友联络资料时，修改记录才包含修改前后的内容。
- **已连接的 AI** 列出所有连接（按 **撤销** 可中断；在用户帐户中重设某个帐户的密码或两步登入，会中断该帐户的所有连接）；**使用记录** 记下每个操作，最新的在前，可按模块、用户、客户端、工具、成功或错误、日期及参数中的文字筛选，分页显示，可 **导出（Excel）**（符合筛选条件的所有记录），并有自己的 **保留** 期限。记录保存每个操作用了哪些栏位，只保留编号、日期、数字和类别的值：姓名、联络资料、备注及其他文字都显示为 **…**（0.19.11 起，所有模块皆然）。
- **当帐户必须设定新密码，或必须设定教会要求的两步登入时，AI 助手就会停止运作**：每次调用及更新连接时都会检查，而不只是在连接时。当事人在 Canon 完成后，若助手要求，再重新连接即可。
- 连接属于这个 Canon 的网址：用另一个网址连到同一个 Canon（或 0.19.11 之前未注明网址的令牌）时，助手会被要求更新连接，它会自动完成。向 Canon 注册却从未连接任何人的应用程序，30 天后会被删除。

## 备份与迁移到 Docker

- **备份**：[设置 → 备份](/settings?tab=backups)。按 **立即备份**，或开启 **自动备份**（每天或每周；较旧的会自动删除）。把 **备份文件夹** 设为 U 盘，或教会自己帐户的同步文件夹（OneDrive、Dropbox），并按 **检查**——也可以让 Canon 自己把每份备份传到教会的 Google 云端硬盘：见 [备份到 Google 云端硬盘](#google-drive)。备份是含个人资料的完整副本，请存放在只有办公室能打开的地方。
- **加密**：备份一律加密（`.db.enc`），并使用自己的密钥——不是数据库的密钥。在这台电脑上可直接还原。在其他电脑上（新的办公室电脑、服务器上的 Docker），或还原在更换恢复密钥之前做的备份时，Canon 会要求输入它所注明编号的 **恢复密钥**。
- **一个文件就包含全部**（0.19.3 起）：已加密的 Canon 的每份备份都包含数据库**和所有已归档的年份**，所以单凭这一个文件——在 U 盘上或 Google 云端硬盘里——就能找回教会的全部资料。还原时也会把它的已归档年份放回去；Canon 原有的已归档年份会移到 `data/pre-restore/` 保留，不会删除。在传送途中损坏或不完整的备份会被拒绝，资料不会有任何改变。
- **0.19.0 以前的 Canon** 在管理员按红色横幅中的 **立即加密……**（或在“设置 → 安全与隐私 → 加密”中按）并再次输入密码之前不会加密。Canon 会先做一份备份，加密数据库，显示恢复密钥一次，再加密它保存的未加密副本——备份、升级前保留的副本和归档的年份——并删除未加密的原文件。不是它制作的数据库文件（例如你自己保存的副本）会被列出并保持原样。当时无法加密的副本（例如 U 盘未插上）会继续列在“设置 → 安全与隐私 → 加密”中：插回后按 **立即加密它们**。已删除的文件在被覆盖前仍可能留在磁盘上，所以也请保持磁盘加密（BitLocker）开启。
- **Canon 已锁定**：若 Canon 以另一个 Windows 帐户启动，或资料搬到新电脑，密钥就无法自动打开。这时 Canon 只会在运行它的电脑上显示一个 **Canon 已锁定** 的页面（其他电脑会被告知到那台电脑操作）：输入恢复密钥后，Canon 会照常启动——之后也会自动打开。
- **0.19.0 以前，备份是用备份密码加密的**（数据库尚未加密时，在“设置 → 备份”中设定）：这些备份仍可用其密码还原。
- **备份密码（未加密的 Canon）**：在备份分页设置 **备份密码**（至少 10 个字符），按 **加密备份**。之后每份备份以及随备份复制的归档文件都会加密（`.db.enc`），即使 U 盘遗失或云端文件夹被分享，会友资料也不会外泄。这台电脑会记住密钥：自动备份不需要有人输入，本机的备份还原时也不需要密码。在另一台电脑上，或还原更换密码之前做的备份时，Canon 会要求输入密码。请把密码和教会的记录一起保存：没有它，任何人都无法打开加密的备份。按 **停止加密** 后，新的备份会恢复为未加密的副本。若加密开启期间这台电脑的密钥文件遗失或损坏，备份会停止并在分页上提示——绝不会改为制作未加密的备份：请重新设置备份密码，或按 **停止加密**。
- **储存空间**（备份分页顶部）：数据库多大、哪些资料占用空间（圣经经文、图片、记录、日志……）、备份文件夹、磁盘剩余空间，以及 Canon 增长多快（根据每天一次的读数），空间不足前会提早警告。
- **还原**：按备份旁的 **还原**，或按 **从文件还原…** 使用这台电脑上的备份文件（U 盘、另一台 Canon）。Canon 会先保存目前资料的副本，所以可以还原那份副本来撤销；备份之后所做的修改会丢失，你可能需要重新登入。如果 Canon 根本无法启动，同一页也列出手动还原的步骤。
- **在 Canon 里更新**（管理员；Windows 电脑或 Mac）：**关于 Canon**（侧边栏底部）有一个 **更新** 卡片。Canon 每天向 GitHub 查询一次是否有新版本（**每天检查一次**；**立即检查** 会马上查询；不会传送任何教会资料），有新版本时侧边栏会显示 **Canon … 已发布**。**立即更新……** 会先备份，再取得新版本并重新启动 Canon：安装所需组件并重新建置期间约有一两分钟无法使用，页面之后会自动重新载入。若新版本无法准备好，Canon 会回到原来的版本，并在卡片上说明。这需要 Canon 是由 `start-canon.bat` / `start-canon.command` 启动的（包括在后台运行）；自己改过内容的 git 副本，请自行用 git 更新。在 Docker 中，Canon 只会告知有新版本：请在服务器上执行 `docker compose pull`，再执行 `docker compose up -d`。
- **手动更新 Canon**：先备份，关闭 Canon 窗口（在后台运行时：右键点 Canon 图标 → **退出**），用新版本的文件覆盖旧文件（或 `git pull`），再启动 `start-canon.bat`（在后台运行时：从“开始”菜单打开 **Canon**）。它会安装并重建有改动的部分。第一次启动时会升级数据库，并把升级前的数据库副本保存在 `data/pre-upgrade/`（保留最新三份）。若新版本有问题，可用这份副本退回旧版本：见 `docs/UPGRADING.md`。旧版本的 Canon 不会打开已被新版本升级的数据库，所以不会损坏它。各版本的改动：`CHANGELOG.md`。
- **迁移到 Docker**（服务器或 NAS）：先在办公室电脑备份，在新机器用 `docker compose pull` 再 `docker compose up -d` 启动 Canon（映像已在 GitHub 上建好），再用 **从文件还原…** 还原备份（或按 `docs/DOCKER.md` 中 “Restoring a backup” 的步骤）。负责电脑的同工几分钟就能完成。

**如果电脑遗失**（被偷、损坏，或换新电脑）：

```flow
[每天] Canon 做一份备份：一个加密文件，包含数据库和所有已归档的年份
存到备份文件夹（U 盘、同步文件夹） | 连接后也存到教会的 Google 云端硬盘
[新电脑] 安装并启动 Canon（或 Docker）：它是空的，有自己的密钥
从 Google 云端硬盘 **复制到这台电脑** | 或从 U 盘 **从文件还原…**
**还原**，输入备份所注明的 **恢复密钥**
教会的资料回来了——会友、记录、账目和已归档的年份
```

**在 Canon 里更新：**

```flow
[管理员] 关于 Canon → **更新** → **立即更新……**
[Canon] 先备份，从 GitHub 取得新版本，然后重新启动
[Canon] 安装所需组件并重新建置（一两分钟）
新版本启动并升级数据库，保留一份副本 | 无法准备好：Canon 回到原来的版本，并说明原因
```

### 备份到 Google 云端硬盘 {#google-drive}

Canon 可以把每次备份也传到教会 Google 云端硬盘里的 **Canon backups** 文件夹，并在那里保留最新的几份。在办公室电脑和 Docker 上都一样可用。
- Canon 只会传送**已加密**的备份（已加密的 Canon 一律如此；0.19.0 以前请先设定备份密码）。Google 没有密钥，所以无法读取备份。
- 每份备份都是完整的：已归档的年份就在里面（0.19.3 起），所以单凭云端硬盘上的一份就能还原全部资料。
- Canon 只能看到和删除它自己放进该文件夹的文件，看不到云端硬盘里的其他内容。
- Canon 使用教会**自己的 Google 登录客户端**登录，只需在 Google Cloud 设定一次，约 10 分钟，免费。

请使用教会的 Google 帐户，而不是个人帐户，这样即使同工更替，备份仍属于教会。

**一、建立 Google Cloud 项目**（在任何电脑上，只需一次）

1. 打开 [console.cloud.google.com](https://console.cloud.google.com)，用教会的 Google 帐户登录。如有提示，请同意条款；不需要付款资料。
2. 在顶部栏打开项目列表，按 **新建项目**（New project）。取个名字，例如 `Canon backups`，按 **创建**，然后在同一列表中选择该项目。

**二、开启 Google Drive API**

3. 在菜单（☰）中打开 **APIs & Services → Library（API 库）**。搜索 **Google Drive API**，打开后按 **启用**（Enable）。

**三、设定登录画面**

4. 在菜单中打开 **Google Auth Platform**（有些帐户是 **APIs & Services → OAuth consent screen**），按 **开始使用**（Get started）。
5. **应用信息**：填写会众认得的应用名称，例如 `Canon – 恩典堂`，以及支持电邮（教会帐户）。按 **下一步**。
6. **受众群体**（Audience）：
   - 一般 Google 帐户选 **外部**（External）；
   - 如果教会使用 Google Workspace，且只有教会自己的帐户会连接，选 **内部**（Internal）。

   按 **下一步**，填写联络电邮，勾选同意，按 **创建**。
7. **数据访问**（Data Access，或 Scopes）：按 **添加或移除范围**，在筛选框输入 `drive.file`，勾选 **…/auth/drive.file**（“查看、编辑、创建和删除您通过此应用使用的特定 Google 云端硬盘文件”），按 **更新**，再按 **保存**。不要添加其他范围。
8. **受众群体 → 发布状态**：按 **发布应用**（Publish app）并确认，使其成为 **正式版**（In production）。
   - 若停留在“测试”，Google 会在 7 天后结束 Canon 的登录，备份会停止，直到有人重新连接。
   - 只用 `drive.file` 权限的应用不需要 Google 审核。
   - 选 **内部** 时没有发布这一步。

**四、建立登录客户端**

9. 打开 **Google Auth Platform → 客户端**（Clients；或 **APIs & Services → Credentials → 创建凭据 → OAuth 客户端 ID**），按 **创建客户端**。
10. **应用类型：电视和输入受限设备**（TV and Limited Input devices）。这种类型让 Canon 用验证码登录，不需要网址，因此在办公室电脑或 Docker 上都能用。名称填 `Canon`，然后按 **创建**。
11. 复制 **客户端 ID**（以 `.apps.googleusercontent.com` 结尾）和 **客户端密钥**（通常以 `GOCSPX-` 开头）。请像密码一样妥善保管。

**五、连接 Canon**

12. 在 Canon 中打开 [设置 → 备份](/settings?tab=backups)。（尚未加密的 0.19.0 以前的 Canon：请先按 **立即加密……**，或在 **加密** 中设定备份密码。）
13. 在 **Google 云端硬盘** 中贴上 **客户端 ID** 和 **客户端密钥**，按 **保存**。
14. 按 **连接 Google 云端硬盘**。Canon 会显示一个验证码（例如 `ABCD-EFGH`）和链接 **google.com/device**。
15. 在任何电脑或手机上打开 google.com/device，输入验证码，选择教会的 Google 帐户，按 **允许**。
    - Google 可能显示“此应用未经 Google 验证”。这是教会自己的应用：按 **高级**，再按 **前往…**。
16. 回到 Canon，几秒钟内卡片就会显示 **已连接** 和该帐户的电邮。

**之后**

- **传送内容**：每次备份后（**立即备份** 和自动备份），Canon 都会把它传到该云端硬盘的 **Canon backups**。**在云端硬盘保留最新的** 决定保留几份，较旧的会被删除。用 `npm run backup` 做的备份，会在下一次半小时检查时传送。卡片会显示最近一次上传，或出了什么问题。
- **立即传送最新备份** 会马上传送，例如用来测试连接。
- **云端硬盘中的备份** 会列出它们。**复制到这台电脑** 会把其中一份放进 **已保存的备份**，再从那里还原。在另一台电脑上，Canon 会要求输入备份密码。
- **中断连接** 会停止上传，并让 Google 撤销 Canon 的访问权。已在云端硬盘的备份会保留。也可以在 [myaccount.google.com/connections](https://myaccount.google.com/connections) 移除访问权。
- **还原较旧的备份** 时，Google 云端硬盘的连接会保留，和备份文件夹一样。
- **Canon 保存的资料**：客户端密钥和 Google 的登录凭证存放在 Canon 的数据库中。请像保护云端硬盘一样，妥善保护办公室电脑和 Canon 的备份。

**遇到问题时**

- *“Google Drive API 未开启”*：请完成第 3 步，等一分钟后再试。
- *“Google 不认得客户端 ID 和密钥”*：请重新复制（第 11 步）。客户端类型必须是 **电视和输入受限设备**；“网页应用”或“桌面应用”类型在这里不能用。
- *约一星期后备份停止，显示“Google 结束了 Canon 的访问”*：应用仍在测试状态。请完成第 8 步，然后再按 **连接 Google 云端硬盘**。
- *验证码过期*：约有 30 分钟可以输入。按 **连接 Google 云端硬盘** 取得新的验证码。
- *云端硬盘已满*：请清出空间，或调低 **在云端硬盘保留最新的**。
- *有人删除了“Canon backups”文件夹*：Canon 会在下次上传时重新建立。

## 常见问题

**“Someone else changed this … after you opened it.”（有人在你打开后修改了这项资料）**
两个人同时修改同一次聚会的资料、同一份聚会记录或同一位会友。Canon 会保留先保存的修改，拒绝后来的保存，不会悄悄覆盖，并说明是谁、在何时修改的。请先复制你输入的内容，重新载入页面看对方的修改，再重新输入你的修改。

**导出的文件在 Excel 中中文变成乱码。**
Canon 导出的是 Excel 文件。CSV 文件仍然可以导入：若另存后出现乱码，请重新另存为 **CSV UTF-8**。用中文编码保存的 CSV 文件，Canon 也可以读取。

**投影的中文字体不对。**
投影只能使用投影电脑上已安装的字体。可在 [投影模板](/slide-templates) 改用其他字体（如黑体或楷体），或在该电脑上安装字体。

**小册子的页序不对。**
请双面打印并选择 **短边翻页**，然后把整叠纸对折。建议先打印一份测试。

**更新后要求重新登入。**
若网址或端口改变、超过 14 天未登入、或密码或两步登入被更改或重设，这是正常的。重新登入即可，资料不会遗失。若更新后画面仍是旧的，请按 Ctrl+F5。

**Canon 打不开。**
在办公室电脑上，“Canon server” 窗口必须保持打开。再双击 `start-canon.bat`（Mac 上是 `start-canon.command`）即可。如果 Canon 自己停止（出错），窗口会在 10 秒后再次启动（最多 10 次）；关闭窗口或按 Ctrl+C 则会完全停止。发生的情况会记录在 `data/logs/canon-<日期>.log`（保留最近 30 天）——可把这个文件交给负责电脑的同工。

**Canon 在后台运行（时钟旁有图标）。**
负责电脑的同工可以把 Canon 设为随电脑启动、不显示窗口（见 `docs/ADMINISTRATION.md`）。时钟旁的 Canon 图标（起初在 **^** 里面）在 Canon 运行时显示绿点，没有运行时显示灰点。点一下就会打开 Canon。右键点它可以查看或复制其他电脑使用的地址、启动 Canon，或选 **退出**（Exit）正常停止 Canon。要再次启动，从“开始”菜单打开 **Canon**，或重新启动电脑。

**某首诗歌没有歌词。**
它是从诗本目录导入的。请在资料库中打开它并输入歌词（须有授权）。

**Claude 看不到某些资料。**
请检查 **设置 → AI / MCP → 模块权限**，并按 **保存 AI 权限**。
